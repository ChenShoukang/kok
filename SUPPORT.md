# 使用帮助 / Support

kok v0.8.1 是预览版。先查看[安装说明](README.md)、[格式支持](docs/FORMATS.md)和[验证范围](docs/VALIDATION_0.8.1.md)。

问题反馈请使用仓库的 [Issue 模板](https://github.com/ChenShoukang/kok/issues/new/choose)，附上版本、Windows / WebView2 版本、复现步骤与预期结果。界面问题可提供已脱敏的截图；媒体问题请说明容器和编码，并优先使用可公开的最小样例。

不要上传 API 密钥、密码、私人原文件、完整资料库或未经检查的日志。诊断日志默认在 `data/logs/kok.log`，分享前遮盖个人路径与内容。安全漏洞请按[安全报告](SECURITY.md)处理，不要公开细节。项目由社区维护，不承诺固定响应时间。

Read the [installation guide](README.en.md), [format limits](docs/FORMATS.en.md) and [validation scope](docs/VALIDATION_0.8.1.md#english) first. Use the repository's [issue templates](https://github.com/ChenShoukang/kok/issues/new/choose) with the app, Windows and WebView2 versions, reproduction steps and expected behavior. Share only redacted screenshots or redistributable minimal samples. Never attach credentials, passwords, personal originals, complete profiles or unchecked logs. Report vulnerabilities through [security instructions](SECURITY.en.md). Community support has no guaranteed response time.
