## 连续任务与范围

- 顶部可选整个资料库、仅所选资料、指定文件夹。文件入口自动切为仅所选资料；原生层同时限制目录、搜索、阅读和模型提出的文件 ID。更改范围后不再发送旧范围的对话历史。
- 会话和草稿保存在当前 Windows 账户加密的本机记录中，保留最近 12 个会话、每个会话最近 80 条界面记录。可以切换、删除和继续会话。重开时未确认的操作会暂停并标为跳过，重新发送要求后才生成新方案，不会自动重放。网络或服务暂时失败时可点“继续任务”，从任务记录续跑，已执行的修改不会重放。
- 执行时可以补充要求，下一轮采用新要求；迟到的旧方案不会执行。也可添加最多 5 项稍后执行的任务。同一任务仍在等待其他确认时，已执行的修改也可以先撤销。停止后保留剩余待办，重开时也不会自动执行；点击“继续待办”后才继续。
- 修改笔记提供前后对照。笔记、标签、分类在执行及撤销前比较当前内容；如果后来被人工修改，保留现状并报告冲突。撤销新建文件同样检查后续内容修改，且始终保留磁盘文件。
- 切换纯净模式、进入私密文件夹或退出时取消任务，忽略迟到回复。纯净模式可离线保存普通资料库会话，不调用 AI；私密文件夹不加载这些记录。

## 技能与用量

内置整理资料、对比资料、读书笔记、制作演示四个指令技能，可自动匹配、手动选择或关闭；仍可使用导入的指令技能。只发送本次使用的技能正文，不执行技能中的脚本。

可设置每任务 1～12 次模型请求，并在“用量设置”填写每百万输入、输出 token 单价及本任务额度。单价与额度须使用同一货币，额度为 0 时关闭费用拦截。请求前按完整消息的 UTF-8 字节保守估算输入，再预留输出上限；额度不足时不开始下一轮。费用是本机按用户填写单价计算，不能代替服务商账单，也不控制 kok 其他 AI 功能的费用。

服务商返回 token 用量时显示其统计；未返回时明确显示保守估算。旧工具结果按完整记录分配上下文额度，旧对话保留本地截取的任务记录与近期消息；这些摘录不是 AI 语义摘要，不会额外调用摘要 API。最近两轮的工具结果保留原文，更早的只保留约 400 字的本地节选。同一任务重复读取相同工具参数可复用结果，执行修改后清除读取缓存。服务商返回缓存命中数时，用量行会显示“缓存命中”。

回复逐步显示，执行阶段与确认卡片分开；输入框和未变化的消息保留原 DOM，避免流式更新丢失输入焦点、选区或滚动位置。中英文、小窗口、深浅皮肤和减少动态效果设置均沿用应用设置。

设计参考：[Pi Agent 事件与任务调整](https://github.com/earendil-works/pi/blob/main/packages/agent/README.md)、[会话](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sessions.md)、[按需技能](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md)。适配现有 C# / WebView2，没有新增 Pi / Node 运行时依赖。

## Agent 首页

新用户默认打开“今天”，可在设置中选择 Agent 或资料库作为启动页。纯净模式和私密文件夹不显示输入框，也不发送任何 AI 请求。

1. 在输入框写下要求，可用“添加资料”指定范围；资料库的 Agent 按钮、查看器的“交给 Agent”和图谱分析的“在 Agent 中继续”会自动带上相关资料。
2. Agent 先用只读工具了解资料，结果显示为灰色卡片。
3. 需要修改时给出确认卡片：写明操作、涉及的资料和原因，笔记、文档和演示文稿附带预览。点“执行”才会生效，“跳过”不做任何改动；完成后可“撤销”。

| 工具 | 类型 | 说明 |
| --- | --- | --- |
| 搜索资料库、阅读资料、查看分类 | 只读，自动执行 | 只读取名称、类型、分类、标签和正文 / 笔记节选；不发送本地路径 |
| 移入分类、添加标签、写入笔记 | 需确认 | 撤销恢复原来的分类、标签或笔记 |
| 新建文档（Markdown / Word / TXT）、新建演示文稿 | 需确认 | 生成新文件；撤销会从资料库移除，文件保留在 kok 文档目录 |
| 打开文件 | 需确认 | 只打开，不修改 |

Agent 不能删除、移动或改写原文件，不能联网搜索，也不执行脚本。导入的 SKILL.md 可在输入框旁选择，只附带当前选中的一条指令。

## 协议与用量

任务循环由原生任务引擎负责：模型调用、只读工具、确认、撤销和续跑都写入当前 Windows 账户加密的任务记录；界面只显示记录快照，并转发确认、跳过、补充要求和停止。

默认使用服务商的原生工具调用（OpenAI 兼容的 `tools` / `tool_calls`，流式返回），覆盖 DeepSeek、OpenAI、通义千问、SiliconFlow、OpenRouter、Ollama、LM Studio 等预设。接口对工具参数返回 400 / 422 时，本任务自动改用兼容 JSON 协议（回复、最多 4 个动作、是否结束），并在对话中注明。两种协议共用同一份工具定义：本机逐项校验工具名、参数长度和文件 ID，格式无效时不执行任何动作。

无效调用不会直接让任务失败：错误作为该调用的工具结果返回模型，最多修正 2 次，仍无效才停止。用户跳过或执行失败的修改也会告知模型，便于调整方案。

请求按固定顺序组织：规则与资料目录在前，历史与本轮结果在后，便于服务商自动复用相同前缀的缓存。仅讨论模式只提供只读工具。

每个任务最多 12 轮，默认 6 轮。没有新的只读动作时任务结束。用量档位沿用图谱分析：省用量、均衡、更多上下文分别限制工具结果约 6,000 / 14,000 / 24,000 字符。这些限制减少请求量，不代表供应商的精确费用。

## 验证

- 原生检查覆盖：合法 / 非法工具、伪造 ID、超出动作数、无效与空回复、文件名越界、智能模式限制和目录中不含本地路径；工具定义注册表、仅讨论模式的只读工具、流式工具调用拼接与调用 ID、无效调用的修正消息，以及接口拒绝工具时的回退信号。
- 隔离界面测试（`tests/agent.cjs`、`tests/agent-reliable.cjs`、`tests/agent-interactions.cjs`）使用本地模拟模型（`tests/agent-fixture.cjs`，同时支持原生工具调用与 JSON 协议）：起手式不发请求、原生工具调用与稳定前缀、只读自动执行、确认前不修改、等待中撤销、跳过、两次修正后停止、JSON 回退、纯净模式、不发送路径、不访问外部网络、原文件哈希不变。

真实模型的回答质量因供应商而异，仍需更多实际资料验证。
