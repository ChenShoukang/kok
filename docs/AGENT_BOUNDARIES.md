# Agent：运行底层与工作流的边界

[English](AGENT_BOUNDARIES.en.md) · [当前 Agent](AGENT_0.8.2.md)

kok 当前不自动派生或合并 session，也不提供 bash 工具。

v0.8.2 开发版在此基础上加入[计划、结果核对、请求追踪与本地 MCP](AGENT_0.8.2.md)。工作流决定计划内容；内核校验工具依据、处理重试和持久状态。内置工具没有任意 shell；用户自己连接的 MCP 程序具有账户权限，外部调用始终单独确认。

| 层次 | 应负责的内容 |
| --- | --- |
| 运行底层 | 模型请求、取消、工具参数与范围校验、操作确认、结果返回、本机日志与会话存取等机制 |
| 工作流 | 任务拆分、是否交接给另一任务、选择证据和工具结果、编写交接记录、判断结果是否合并 |
| 界面 | 展示阶段、证据和改动，让用户选择、确认、纠正与停止 |

fork、事件持久化和分支读取本身可以作为底层能力；不应把“每个任务自动复制整个 session、执行完自动合并”设为通用默认策略。恢复会话也不应自动重放未完成的写入操作。

## 日志与模型上下文是两件事

完整工具调用及结果可以作为本机事件日志保存，帮助恢复和排查；发送给模型的上下文应按任务选择。工作流交接时引用已有记录，携带目标、已验证事实与来源、完成的操作、未完成事项和下一步，避免复制所有输出、反复压缩或重复计费。交接记录不是对原资料的修改授权，合并时仍须检查内容冲突。

## 当前实现

v0.8.1 已将执行循环移入原生内核，完整工具事件使用 DPAPI 加密保存；支持显式恢复与按引用交接。界面刷新会连接已有任务，进程重启需手动继续；写入不会盲目重放。见[本轮架构与待办](ARCHITECTURE_0.8.1.md)。
