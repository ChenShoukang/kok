# Agent 首页与交互

kok 以 Agent 为主要协作入口，资料库同时保留独立的观看、收听和阅读体验。
资料可按需用于创作与处理；作品、内容欣赏和 Agent 的功能归属见[功能结构方案](CREATION_PRODUCT_FLOW.md)。

- 智能模式未指定启动页时默认进入 Agent；已有的启动页偏好继续生效。
- 一级入口按使用场景组织为 Agent、我的作品、资料库：Agent 提问与执行任务，我的作品继续创作与项目管理，
  资料库独立观看、收听、阅读并保留进度与收藏。文件类型和工具留在各自区域内部，不再占据一级入口。
  品牌标志返回 Agent。私密文件夹和设置固定在侧栏底部。
- Agent 页收起全局资料库搜索、新建文档和导入栏，主要区域围绕任务输入展开。
- 空白任务以一句提问和居中输入区开始，建议为整理思路、制定计划、制作演示；
  添加资料后建议跟随资料类型变化，范围按钮继续展示实际处理范围。
- 添加资料窗口支持从本机直接导入，导入后自动选中本次新增资料；原任务草稿保留。
  已有资料也可直接勾选，批次仍受 24 份资料的范围限制。
- 发送后转为对话布局，输入区移动到底部；保留原输入节点、草稿、焦点和选区。
  位移仅用 transform，遵循减少动态效果设置，不在流式更新时重复播放。
- 新任务、会话与权限是紧凑图标操作；任务记录、长期记忆和计划任务在更多菜单。
  MCP 入口随高级设置展开。菜单在后台重绘时保留触发器和键盘焦点。
- 默认深色底色为 `#0b0b0e`，输入区为 `#151519`；紫色用于选中态和强调。
  浅色采用中性近白底色。用户的自定义颜色和阅读纸张设置继续独立生效。
- 输入区使用连续表面，避免给 textarea 再套一层底板；圆形发送按钮、轻量建议
  入口和明确的聚焦状态共同表达可操作性。审批区域占独立一行，成果可打开和追溯。

参考开源项目的实际结构：

| 来源 | 参考方向 |
| --- | --- |
| [LobeHub ChatInput](https://github.com/lobehub/lobehub/tree/main/src/features/ChatInput) | 输入区承载主要任务，辅助动作按需展开。 |
| [Open WebUI MessageInput](https://github.com/open-webui/open-webui/blob/main/src/lib/components/chat/MessageInput.svelte) | 连续输入表面、紧凑附件菜单与圆形发送控制。 |
| [LibreChat ChatView](https://github.com/LibreChat-AI/LibreChat/blob/main/client/src/components/Chat/ChatView.tsx) | 空白页、会话、输入和审批状态分别组织，任务持续时保留输入状态。 |

实现沿用 kok 的组件、离线图标和 WAAPI，没有复制外部应用代码或新增前端框架。
原生任务引擎、本地分流、检索、权限与撤销流程沿用现有实现。
