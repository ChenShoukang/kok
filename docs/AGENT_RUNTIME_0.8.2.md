# Agent 运行能力：上下文、记忆、子任务与隔离计算

[English](AGENT_RUNTIME_0.8.2.en.md) · [Agent 指南](AGENT_0.8.2.md) · [本轮验证](VALIDATION_RUNTIME_0.8.2.md)

这些是 v0.8.2 的后续本地开发改动。打开 Agent 顶部的“能力与权限”，按任务选择使用记忆、子代理和隔离计算。配置开关本身不请求模型。已有资料、任务和模式继续沿用。

## 长会话与检查点

语义压缩保留原始目标、补充要求、当前计划和最近两轮完整消息；较早的完整轮次交给模型生成摘要。调用与工具结果成对处理，原始事件仍完整加密保存在本机。模型可用 `recall_result` 按调用 ID 取回准确内容，无需重跑原工具。

摘要有独立追踪事件，使用原任务的请求与费用额度；额度不足以同时摘要并继续回答时跳过压缩。要求、工具状态或来源变化会使旧检查点失效，不能用旧摘要授权修改。界面可以打开检查点看摘要。

“资料上下文上限”使用 UTF-8 字节作为保守 token 上界，**不是针对所有模型的精确 tokenizer**，也不包含固定工具定义的大小。实际 token 用量以服务商返回值为准。摘要可能遗漏细节，准确事实仍应回查原工具结果。

## 用户管理的长期记忆

“长期记忆”可新建、编辑、删除和撤销记录。记录默认与所选资料关联；也可由用户明确保存为个人记忆。任务需要打开“长期记忆”后，才会按相关词本地检索少量记录并提供给模型。当前是本地词项检索，没有额外的向量数据库或 embedding API。

Agent 使用 `remember_memory` 提议来源明确的记忆，确认后才保存。来源变化或不在当前任务范围内的记忆不会自动引用；手动重新审核、编辑保存后可更新来源版本。记忆始终作为不可信资料，不能授予工具权限或替代原始证据。

最多 128 条，每条正文 2,000 字符；记录及最近 80 次修改使用当前 Windows 账户 DPAPI 加密，独立于普通资料库 JSON。修改比较版本，撤销会保护后来的编辑。私密文件夹禁用；API 密钥形状的内容拒绝保存。此防误存规则不保证发现所有敏感信息，用户仍决定应该记住什么。

## 明确委派的只读子代理

`delegate_task` 的确认卡片列出目标、资料和请求上限。子任务只收到明确的委派目标与所选资料，不自动复制父会话、历史或技能指令。它能搜索、阅读、回查结果、维护计划和核对结果；不能写资料、调用 MCP、运行代码、读取记忆或继续派生子任务。

父子所有模型请求、重试和摘要计入父任务原预算。启动时为父任务最后核对保留请求，最多一层、每个父任务至多四次委派。停止、模式变化和更新父要求会取消旧子任务。子任务报告、事件和用量可单独查看，未完成的子任务不作为成功工具证据。

任务记录保存父子关系。程序中断不会自动重放委派；恢复父任务后需要重新确认，已结束的子任务可核对其既有报告。子任务请求额度不会因恢复而重置。

## JavaScript 隔离计算与产物

`run_code` 先显示代码和 JSON 输入，单独确认后在本地 QuickJS WebAssembly 解释器运行。代码写成表达式或返回值的 IIFE，只能使用标准 JavaScript 与 `INPUT`。例如输入 `{"budget":1800,"spent":1200}`，表达式 `INPUT.budget-INPUT.spent` 返回 `600`。

每次使用新解释器和独立工作线程，不暴露文件、网络、DOM、环境变量、`process`、`require` 或 shell 接口；限制 16 MiB 堆、256 KiB 栈、约 1.2 秒计算和 16,000 字符输出，工作线程还有独立超时。结果可审核后保存为 Markdown、TXT 或 Word 文档。

这是 **JavaScript/WASM 语言运行时隔离**，没有提供任意 Python/Bash、Docker 或 Windows 虚拟机执行。已连接的 MCP 程序仍按原有账户权限运行，不自动进入这个边界。运行 kok 不需要安装 Node.js。

## 其他执行基础

每个任务可以进一步收紧模型可用的工具；服务端也校验，隐藏按钮不是授权机制。计划和完成核对工具由内核保留。子任务、代码及外部 MCP 调用排除批量批准。共享预算、逐请求用途、可恢复事件、结果回查、记忆版本和可保存产物共同组成实际执行路径。

原有技能指令、工具模块注册、人工审核、冲突安全撤销、任务内补充信息、配方与活动中心继续可用。本轮没有宣称目标语义可由系统独立验收。

## 参考实现

- [Pi 的 compaction](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/compaction/compaction.ts)：保留近期消息，在完整调用轮次边界创建检查点。
- [Deep Agents 的子代理](https://github.com/langchain-ai/deepagents/blob/main/libs/deepagents/deepagents/middleware/subagents.py)：明确任务、隔离上下文与限制递归。
- [Letta 的按需记忆读取](https://github.com/letta-ai/letta-code/blob/main/src/tools/descriptions/Memory.md)：按相关性逐步读取，避免把所有记忆塞入提示词。
- [QuickJS Emscripten](https://github.com/justjake/quickjs-emscripten)：本地 WASM 解释器、运行时间与内存限制。仅内置 release-sync 变体，许可见 `docs/licenses/QuickJS-Emscripten-MIT.txt`。

前三者作为架构参考，不引入它们的运行框架。QuickJS 的固定版本文件与校验值由构建脚本管理。功能验证及真实模型质量仍需分别报告。
