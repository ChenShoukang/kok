# v0.5.1 · DeepSeek 内容验证

2026-10-25，使用本机已保存的 DeepSeek `deepseek-flash` 配置，通过 kok 的真实 `ChatAsync`、`TranslateAsync`、`OrganizeAsync` 方法验证。没有修改模型配置，没有将密钥写入报告。全部输入是自编短资料，不含个人文件内容。

本轮 10 组均通过预设检查，并人工复核回复。单次完成约 0.86–2.06 秒；这是本次样例的实测时间，不代表固定延迟。仅产生短小的真实 API 请求，未取得服务商账单或费用明细。

## 三项新工具的真实检查

新增工具后，另外通过隔离的 kok 窗口测试了两份自编资料对比、两份划线与笔记回顾，以及三段自编字幕生成目录。三项真实 DeepSeek 请求均返回可用结果，逐项复核了引用和内容。

- 对比能区分「论证规范」与「记录规范」，引用分别指向两份资料。
- 回顾能区分划线、个人想法和研究意图，并指出两份笔记的对应关系。
- 目录生成「阅读与记忆的相关性≠因果 / 区分个人想法与原文证据 / 每日回顾笔记并发现新问题」，跳转时间由程序保留为 `0 / 125 / 250` 秒。
- 实测发现收起动画结束前快速重开面板会误关闭，已加操作代次校验，并在真实调用流程中验证。
- 人工复核发现原回复偏长、笔记标题夹带英文，已缩短默认分析并固定标题语言；只补测了一条真实回顾请求，回复为 317 字符，含中文标题与有效引用。

这些检查验证短内容处理及接口解析，不代表已验证整部视频、整本长书、OCR 或所有模型的表现。图像理解未在本轮测试。引用格式有效也不等于所有回答必然有充分依据，仍需按具体原文核对。

带完整自编样例回复的机器结果位于忽略的 `test-output/deepseek-content-results.json`，不包含密钥。测试没有发布到 GitHub。
