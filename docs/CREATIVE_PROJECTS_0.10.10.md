# 创作项目（v0.10.10）

[项目首页](../README.md) · [功能结构](CREATION_PRODUCT_FLOW.md) · [本次验证](VALIDATION_0.10.10.md)

创作项目把**一件作品**的目标、风格要求、资料、相关会话和多个成果放在一起。打开项目就能继续做，隔天换一个会话也不会丢掉要求。

## 新建与打开

「我的作品」页顶部新增 **创作项目** 区域：

- **新建创作项目**：填写名称、目标、风格/验收要求、状态（draft/active/done），并从资料库挑选资料加入项目。
- 项目卡片显示名称、目标摘要、状态、`资料 N · 成果 M` 和更新时间，可直接 **打开项目** 或 **继续创作**。
- 项目详情列出目标、要求、资料（可直接打开编辑）、成果、相关会话，并可随时 **编辑项目**。

项目保存在资料库的 workspace 记录里，走既有的操作审计与撤销链路（不是新数据库表）；私密文件夹不启用 AI，也不会出现在项目里。

## 继续创作

从项目点「继续创作」会切到 Agent 并新建一个会话，输入框上方出现项目横幅（名称 · 目标 · 资料/成果数）：

- 任务自动带上项目的**目标与要求**（作为稳定前缀注入，不随每轮变化）、**资料范围**（项目资料，最多 24 份；你显式选择的范围优先）和**已有成果清单**，模型知道这是哪个项目的延续。
- 任务产生的**会话**和**成果**会写回项目：会话进入 `sessions`，创建/修改的文档与演示文稿进入 `artifacts`（可去重、可撤销）。
- 点横幅上的 × 可退出项目上下文；新建会话不会丢横幅，横幅会随会话快照一起恢复。
- 成果面板在有项目时**优先展示项目成果**（即使切换会话、切分支也仍在项目里），同时保留当前会话产生的成果。

## 版本历史（本轮原生底座）

本轮同时实现了版本历史的基础 API：按作品列出版本、读取某版本改动前后的文本与 hash、恢复任意版本（恢复本身是一次可撤销的新操作）。版本侧栏、差异对比和手改保存前预览会在下一轮接到界面上。

## 边界

- 项目本质是 space 记录：目前「空间」页也会列出项目，后续版本会按 `kind` 过滤。
- 项目简报由 kok 宿主生成并标记为不可信数据；它只提供背景，不改变审批、证据核对、撤销或沙箱语义。
- 本轮没有加入手改 diff、版本 UI 或项目级成果清理；这些在后续轮次。
