# v0.6.2 · 石墨界面

[English](GRAPHITE_0.6.2.en.md) · [返回](../README.md)

深色石墨、浅色霜面，共用清晰的文字层级、冰蓝反馈和轻量拟物按钮。默认字体为内置得意黑；设置中仍可选择霞鹜文楷、系统字体或导入本地字体。已有的主题、字体和阅读纸色优先。

| 位置 | 改进 |
| --- | --- |
| 资料库 | 宽侧栏显示图标和文字；小窗口自动收成图标栏；书与文档用标题封面，音乐保留真实封面，没有封面时显示唱片 |
| 阅读与 PDF | 内凹分段工具条、连续选中反馈和冰蓝进度；正文跟随常用字体，也可独立选择黑体、宋体、文楷等 |
| 视频与照片 | 统一深色观看区、标题和控制条，浅色界面中同样保持可读；紧凑操作和可滚动照片工具条 |
| 音乐播放条 | 同材质的播放按钮、清晰状态和适应窗口的排列；进入页面不会自动播放 |
| 弹窗与菜单 | 沿用可中断的单套动画，避免重叠缩放；设置窗口尺寸稳定，提示消息带可见指示灯 |

保留[知识图谱](KNOWLEDGE_0.6.1.md)、[新建文档与自动保存](DOCUMENTS_0.6.1.md)、翻译、字幕生成、私密文件夹与已有影音编辑功能。[动画说明](MOTION_0.6.1.md)包含时间、中断、减少动态效果和开源参考。

源码和便携包不包含个人资料库、模型配置或密钥。媒体解码仍依赖 WebView2 的实际编码支持，下载和语音组件按需安装。完整范围见[格式兼容性](FORMATS.md)。
