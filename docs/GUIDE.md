# kok 使用指南

v0.9.0 新增正文索引、本机语义检索、浏览器采集、Windows OCR 与便携导出恢复，操作和边界见[新功能指南](LIBRARY_0.9.0.md)。

[English](GUIDE.en.md) · [项目首页](../README.md) · [文档目录](README.md)

kok 把本地影音、图片、文档和电子书接到同一套整理与记录流程里。你可以只用它播放和阅读，也可以进一步做笔记、收集摘录、建立主题空间，再用 AI 辅助产出内容。以下按 v0.8.1 Preview 的实际功能介绍；可见入口会随模式、模块开关和文件格式变化。

## 先分清四种东西

| 名称 | 用来做什么 |
| --- | --- |
| 资料库 | 收录本地文件，按视频、照片、音乐、文档、读书浏览；支持分类、收藏、最近打开、排序和搜索 |
| 空间 | 把同一主题的文件与摘录放在一起；一个资料可以加入多个空间，切换网格、画布、时间线或图谱 |
| 摘录 | 保留一段文字、一个时间段或一块照片区域，并记录来源；点击可以回到原处，时间段摘录本身不生成新的音视频文件 |
| 智能集合 | 保存一组筛选条件，例如“最近七天导入、尚未阅读的 PDF”；匹配结果随资料变化更新，本地筛选不需要 AI |

“分类”和“空间”改变的是应用内的组织关系，不会替你移动磁盘文件。

## 收集、查找与继续使用

拖入文件或文件夹，或点击“导入文件”。kok 识别支持的文件类型，并跳过已经收录的相同路径。也可以扫描自己指定的文件夹发现新文件；本地扫描和归类本身不调用模型。

从“今天”继续上次的阅读与播放、查看最近摘录和进行中的任务；从资料库按类型浏览。搜索可覆盖已建立索引的文件名、正文、笔记、批注、字幕等，格式边界见[兼容性清单](FORMATS.md)。扫描 PDF 不会凭空产生可检索文字。

普通分类支持拖放归类。拖到私密文件夹时，需要确认和密码；不要把普通分类理解为加密保护。

## 看视频、听音乐、看照片

| 类型 | 可以使用的功能 |
| --- | --- |
| 视频 | 续播、0.5×–3× 倍速、静音片段加速、无边框全屏、横竖屏适配、封面、右键属性；自动匹配或手动加载外挂字幕，可设置空格播放和方向键跳转等快捷键。画中画取决于内核支持 |
| 音乐与音频 | 按专辑、歌手、个人音频或全部音频浏览；读取标签和内嵌封面，手动修正或选择联网匹配候选；播放队列、续播、随机与循环。录音、播客和音效也可单独归纳 |
| 照片 | 滚轮缩放、放大后拖动、旋转、幻灯片；自由或固定比例裁剪、调色、滤镜、暗角、翻转与原图对比；文字、画笔、箭头、遮挡、图层和撤销 / 重做 |

支持独立、可移动的预览窗口；双击照片或文档的内容空白处，可让该窗口退到主窗口后面。共用查看器提供“查看 / 编辑 / 笔记 / AI”入口，`F8` 切换工作与沉浸布局，按资料类型记住选择。

## 阅读、标记与自己写文档

在“新建”中创建 Markdown、DOCX、TXT 或 PPTX。文字文档提供编辑 / 源码 / 预览、自动保存和 `Ctrl S`；新建格式与入口会跟随对应模块的启停。

- **读书**：EPUB 目录、TXT 章节识别、全文搜索、书签与续读；单页、自适应双页或上下滚动，滚轮翻页；独立阅读字体、字号、行距、字距、段落留白、正文宽度和护眼配色。
- **PDF**：本地页面预览、文字搜索、缩放、深色与易读文字；划线、高亮、批注和位置插入文字。标记保存在 kok 中，不直接写回原 PDF。
- **PPTX**：幻灯片列表、备注与放映，基础文字 / 页面编辑和导出副本；支持在可编辑的文字或对象处右键提出 AI 修改，先看预览再应用。
- **笔记**：在当前资料旁记录想法，或选中文字后划线、高亮并补充批注。Markdown 支持 `[[链接]]` 补全、反向链接、标签、大纲、待办和日常 / 会议 / 阅读模板。

“知识图谱”用于查看资料和笔记的关系，可以搜索、缩放、拖动，并按范围筛选。它展示已有链接与关系，不会自动证明两份资料存在事实关联；当前图谱最多显示 500 个节点。

## 把看过的内容留下来

打开资料，在查看器旁的详情区域选择“创建摘录”：文字可使用当前选区；音视频可记录起止时间；照片可拖动框选区域。给摘录起名、写下内容或想法，保存后即可从“摘录”找回。

摘录和原文件都能加入空间；也可拖到笔记中形成引用，或拖到 PPT 中创建一页。来源文件仍需存在，摘录不会替你备份原文件。空间画布适合手动排布，时间线适合按时间回看，图谱适合查看已建立的关系。

例如，建一个“旅行记录”空间：放入行程、照片、录音和视频，再摘下路线段落、精彩时间点与照片局部，用它们整理旅行笔记或演示文稿。

## AI 在哪里帮得上忙

切换到智能模式，在 **设置 → 功能 → AI 服务**配置兼容接口。读取模型列表与测试连接、服务预设和密钥保护方式见[AI 配置](AI_PROVIDERS.md)。进入智能模式不会自行请求模型；真正执行 AI 功能时，选定内容才会发到配置的服务。

| 入口 | 适合的任务 |
| --- | --- |
| 查看器 / 右侧 AI | 针对当前资料、选文或笔记提问；解释一个词或一段话；支持的编辑区域可右键请求改写 |
| 翻译 | 选词翻译；文档 / 电子书左右对照或仅译文，双向滚动、本机译文与标记恢复；导出支持的对应格式副本 |
| 多文件对比 | 手动选多份可读资料，预览引用，再比较共同点、差异和依据；可回到来源 |
| 笔记回顾 | 从划线、批注和个人笔记中整理回顾，选择加入相关旧笔记，保存报告或导出 Markdown |
| 视频字幕 | 翻译已有字幕、生成可跳转的字幕目录；无字幕时可另行配置本地 Whisper 或语音 API 生成字幕 |
| Agent | 在所选资料、指定分类或资料库范围内搜索、阅读和讨论；提出分类、标签、笔记、新建文档和演示等可审核操作 |

视频问答主要使用字幕，支持时可附当前画面；长文和长字幕可能节选。支持图片的模型才能理解画面，聊天 API 本身不等于语音识别。不要把一段节选的回答当作对整部电影或整本书的完整分析。

### 给 Agent 一个范围清楚的任务

可以选中文件后点 Agent、把资料拖给 Agent，或在内容旁打开 AI。先选“仅讨论”了解资料；要产生修改时再用协作方式。

可尝试：

- “只根据选中的三份文档，对比观点，并列出需要回看原文的地方。”
- “给这些阅读资料建议分类和标签，先展示方案。”
- “把这些资料中的要点整理成 Markdown 笔记。”
- “根据这份文字材料创建一份简洁的演示草稿。”

读取步骤与来源可以展开查看；修改先显示确认卡片，可执行、跳过或撤销。切换范围不会继续发送旧范围的对话。停止、续跑、会话恢复和交接都有显式入口，重开不会自动重放未确认的写入。

内置整理、对比、读书笔记、制作演示四类指令技能，支持导入自己的指令技能；技能不会自动获得脚本执行权限。可设置请求轮数、上下文用量与任务额度；费用按填写的单价估算，不代替服务商账单。详见[Agent 功能与边界](AGENT_0.7.2.md)和[审核交互](AGENT_INTERACTIONS.md)。

## 把重复步骤存成配方

从“配方”新建、选择资料并编辑步骤顺序。内置四种起点：

| 模板思路 | 需要 AI 吗 |
| --- | --- |
| 读取 → 笔记 | 不需要 |
| 读取 → 摘要 → 笔记 | 摘要需要 |
| 读取 → 摘要 → 演示 | 摘要需要 |
| 已有字幕 → 摘要 → 笔记 → 演示 | 摘要需要；须先有可读字幕 |

运行前预览整套步骤并确认；这是一组受支持能力的串联，不是任意脚本执行器。输出可进入操作历史，来源发生变化时会阻止继续沿用旧计划。

“活动”集中显示后台进度与取消；只有支持续跑的任务才有暂停 / 继续。“历史”可查看并撤销已接入的修改，遇到后续人工改动会保留现状并提示冲突。“回顾”按天展示使用与进度记录，可另存为笔记。

## 编辑导出与可选组件

| 功能 | 导出与限制 |
| --- | --- |
| 照片 | 另存 PNG / JPEG，保留原图；动图编辑按静态画面处理，编辑输出长边最多 4096 px |
| 音视频 | 支持剪切、分割、跨素材时间线及片段字幕；实际媒体导出使用可选 FFmpeg / FFprobe |
| DOCX / EPUB | 正文编辑和导出重建简洁排版，不保证复杂原版式一致；新建的托管文档可以直接保存编辑 |
| PDF | 合并、重排、旋转和页面标注；编辑过的画布页面按图像导出，其余页面保留原内容；扫描件仍需外部 OCR |
| PPTX | 基础文字和幻灯片编辑、备注与导出；复杂母版、图表、动画和嵌入对象不能完整还原 |
| 视频下载 | Bilibili / YouTube / 抖音、通用网页与直链；画质 / 资源选择、仅音频、字幕、队列、续传、登录会话与入库。分轨 / M3U8 / DASH 合并需可选组件，网站变更可能导致解析失效，不保证所有登录、加密或付费内容可用 |
| 语音字幕 | 本地识别需另行准备引擎 / 模型；语音 API 独立配置，不会把聊天服务的密钥转发过去 |

## 隐私、备份与常用设置

纯净模式阻止 AI 请求，基础本地功能离线可用。智能模式不是全程联网开关；文件读取、分类和本地空间整理仍在本机完成。界面可选中英文、深浅色、背景与玻璃颜色、内置字体及模块开关。

私密文件夹属于资料库内的密码文件夹，不是第三种应用模式。加密应用内记录、笔记、封面及关联数据，禁用 AI；支持离开窗口、最小化和闲置自动锁定。移入前需确认，完成加密保存后清理可追踪的普通库记录与副本。

**原文件不加密；此前独立 AI 历史、导出和外部备份不会追溯加密；密码无法找回。** 普通 JSON 导出与私密 `.kokvault` 备份都不包含原文件。备份、恢复和清理范围以[私密说明](MODES.md)为准。

| 快捷键 | 用途 |
| --- | --- |
| `Ctrl K` | 搜索与命令 |
| `Ctrl N` / `Ctrl S` | 新建文档 / 保存支持的编辑内容 |
| `F8` | 查看器工作 / 沉浸布局 |
| `Ctrl Shift I` / `Ctrl Shift A` | 资料检查器 / 上下文 AI（功能可用时） |
| 视频 `空格`、`← / →`、`F` | 播放暂停、跳转、全屏；可在设置自定义 |
| `Ctrl Shift L` | 锁定私密文件夹 |

实际格式支持见[清单](FORMATS.md)，已验证与未验证范围见[验证记录](VALIDATION_0.8.1.md)，问题反馈见[支持说明](../SUPPORT.md)。
