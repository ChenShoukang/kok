# v0.9.0：检索、采集与可恢复资料库

[English](LIBRARY_0.9.0.en.md) · [项目首页](../README.md) · [验证记录](VALIDATION_0.9.0.md)

从侧栏“资料检索与备份”或设置中的同名入口打开。正文索引、导出恢复、采集和 OCR 可在纯净模式使用；本机语义模型仍属于 AI，只在智能模式请求。私密文件夹不使用这些普通库服务。

## 先建立正文索引

导入或编辑后会安排增量更新；也可点击“更新正文索引”。面板显示每份资料的状态、片段数量、提取失败和部分覆盖。更新不会修改原文件。

索引包括标题、笔记、标签、独立摘录、支持格式的正文、PDF 文字层、PPTX 文字与备注、第一条可用字幕轨。结果保留页码、章节、字幕时间或摘录原锚点。点击结果会重新核对来源版本，再打开原处。文件被修改、删除或移入私密后，旧片段不能继续供普通检索读取。

单源最多 2,000 个片段，每片段最多 1,200 字符、重叠 100 字符；部分格式正文提取上限 32 MB，PDF 文字提取最多 2,000 页 / 200 万字符。达到限制会显示部分或失败状态；扫描 PDF 没有文字层时提示 OCR。页码 / 时间定位可用，复杂排版中的字符位置可能需要人工确认。大资料库尚无统一容量承诺。

## 按需启用本机语义检索

先自行安装 [Ollama](https://ollama.com/) 和 embedding 模型，例如：

```powershell
ollama pull embeddinggemma
```

在面板填入本机地址（默认 `http://127.0.0.1:11434`）与模型名称，启用并保存，然后点击“建立语义索引”。聊天模型与 embedding 分别配置，DeepSeek 聊天配置不会自动成为 embedding 配置。kok 不自动下载模型，不将 embedding 文本发到远程地址。模型的资源需求及许可由所选模型决定。

检索有三种方式：文字匹配、语义、混合。混合使用 FTS5 与向量名次融合；全局搜索和 Agent 检索复用这一路径。结果包含来源片段，近似相关不等于事实回答。最低相似度默认 0.35，可在面板调整；无答案查询仍可能出现近似候选，需要查看原文。真实对照结果见[验证记录](VALIDATION_0.9.0.md)。

向量在本地 SQLite 中缓存。模型名称、端点、手动版本标记或分块版本变化后需要重建；同名模型重新下载后也应更新版本标记。模型未启用、未建索引、不可用或维度不兼容时回到文字匹配并显示提示。进入纯净模式会阻止新的 embedding 请求。

## 快速记录与浏览器采集

直接在“随手记录”粘贴标题、网址与文字，保存到 Inbox 收件箱。保存网页正文、选区或图片可用随包的 Chrome / Edge 源码扩展：

1. 在“浏览器与外部 Agent”勾选允许配对浏览器保存资料，应用权限，再显示配对配置。
2. 在浏览器扩展管理页开启开发者模式，“加载已解压的扩展”，选择发布包中的 `browser-extension` 文件夹。
3. 打开扩展设置，填入 kok 显示的 Capture URL 与配对密钥。应用需保持打开。
4. 点击扩展保存当前网页文字，或右键保存选区 / 图片；查看成功或失败状态后重试。图片采集可能要求授权该站点。

采集保存来源 URL、时间与内容指纹；重复提交相同内容会返回已有记录。网页首版保存清理后的文字，不承诺完整排版、登录会话或网页资源离线镜像。图片另存 PNG，原网页保持不变。扩展源码见[安装说明](../browser-extension/README.md)，未发布到扩展商店。

## 本机 OCR 与原件维护

选择图片或 PDF，在“本机文字识别”运行；PDF 一次可选 1–20 页。识别使用 Windows 已安装的 OCR 语言，失败时先检查 Windows 语言功能。结果进入页码索引，不写回图片 / PDF。没有提供图片含义理解或以图搜图。

“查找完全相同的文件”按文件字节的 SHA-256 分组，不自动删除。原件移动后，“选择新位置并预览”创建可审核的重新关联提案，在历史中应用或撤销，保留来源 ID 与摘录关系。

## 导出、恢复与换机

“导出便携资料库”生成 `.koklib`，本质是标准 ZIP，包括：

- `manifest.json`：版本 1 的开放契约、资料 ID、标签、来源、路径引用、工作区对象和附件大小 / SHA-256。
- `notes/*.md`：笔记、托管文档文字与摘录，便于其他软件阅读。
- `clips.json`、`spaces.json`：摘录锚点与空间关系。
- `sources/*`：始终包含托管文档；其余原件需勾选包含后才打包。

单个附件最多 2 GB，总附件最多 8 GB；最多恢复 10,000 份资料。便携包用于普通资料互通和快照式传输，不包含 AI 密钥、MCP 配对、聊天 / 任务历史、记忆、私密库、封面缓存或 embedding 索引，也不替代完整数据目录备份。导出的普通资料是明文，按自己的资料保密需要保存。

恢复先显示数量，再选择新资料库所在的文件夹；校验格式、ID、关系、附件大小与哈希后创建独立新库。现有库继续打开，失败不会覆盖已有库。点击“打开新资料库”可在独立窗口检查内容，新库默认纯净模式。也可运行 `kok.exe --data-dir "新资料库目录"`。

未随包的外部原件只在明确提供旧根目录 / 新根目录映射后重新关联，其余保留为缺失项，再逐项重连。恢复后重建正文 / 语义索引，并重新配置模型和外部连接。设备间使用导出 → 复制 → 新目录恢复；没有后台云同步、写入所有权交接、冲突合并或移动客户端。不要将活动 SQLite 文件直接放进同步盘当作同步功能。

## 让外部 Agent 只读查询

允许“外部 Agent 只读查询”，选择当前普通资料范围后应用，复制显示的 MCP 配置到支持 stdio MCP 的客户端。命令形态：

```json
{
  "mcpServers": {
    "kok": {
      "command": "D:\\Apps\\kok\\kok.exe",
      "args": ["--mcp", "--data-dir", "D:\\Apps\\kok\\data"]
    }
  }
}
```

使用你自己的绝对路径；运行中的 kok 必须打开这个资料库。协议版本为 `2025-11-25`，公开 transport 为 stdio。进程通过本机加密配置连接当前库，密钥不出现在命令行。内部回环 HTTP 桥接不是通用远程 Streamable HTTP 服务。

只公开 `list_sources`（分页）、`search_library`（词面）和 `read_excerpt` 三个工具，返回允许范围的元数据或片段，不返回本地文件路径。首次先建立正文索引。授权绑定当次所选来源，新入库内容不会自动共享；可随时关闭。私密或正在切换的资料库拒绝读取。采集与读取使用不同凭据，连接默认关闭，仅监听回环地址。此版本没有外部写入工具、远程 MCP / OAuth 或各第三方客户端的兼容认证。

## Agent 的新核对能力

保留已有计划、审批、记忆、只读委派和隔离计算，新增精确十进制 `calculate` 工具、读取回查及连续批准写入的证据链校验；拒绝写入不会被计为成功。任务批准可选逐次、只读或当前任务的有限授权。事件包含版本，中断时保留已到达的正文并标记中断。核对工具回执仍不能保证模型的每一句语义判断正确，真实模型测试与固定响应回放分开报告。

元数据写入后的“完成”现在要求有实际读回回执；缺少读回时原生层拒绝完成。外部连接每次重新启用会更换凭据，浏览器扩展需重新配对。

正文索引会增量更新；更改资料后需再次点击“建立语义索引”，未变片段会复用向量。当前内容版本同时包含元数据，编辑元数据也会使旧提取片段失效；扫描件必要时重新运行 OCR。
