# 使用模式与私密文件夹

v0.9.0 新增正文索引、本机语义检索、浏览器采集、Windows OCR 与便携导出恢复，操作和边界见[新功能指南](LIBRARY_0.9.0.md)。

[English](MODES.en.md) · [文档索引](README.md)

v0.3.1 首次进入只选择纯净或智能模式。升级后的旧资料库如果尚未选择，也会显示选择页。两枚矢量图标、玻璃卡片和柔和动画介绍这两种方式；支持中英文、小窗口及系统“减少动态效果”。私密功能是资料库内的一个文件夹，不是第三种使用模式。

**纯净模式**保留本地视频、音乐、照片、文档和读书功能，包括媒体比例自适应、字幕加载、照片编辑、划线、荧光标记和笔记。界面隐藏 AI、智能整理与额外侧栏分组，只保留主要入口。AI 翻译、问答、归纳请求会在原生程序中被阻止，自动翻译和后台自动扫描也不会启动。应用页面的外部 HTTP / HTTPS 资源请求会被拦截，本地界面、PDF.js、字体和媒体无需联网即可加载。

**智能模式**保留完整界面与本地功能，并启用可选 AI 翻译、智能整理和内容对话。第一次进入会显示大模型提示，介绍接口配置、发送内容与服务商计费；可以直接开始使用已有配置，也可以打开模型配置。进入模式本身不调用模型。启用自动翻译后，打开相关内容仍会按该设置触发请求。

设置里的“更改模式”可随时重新选择。模式与首次提示状态持久保存，已看过的智能提示不重复展示。切回纯净模式会取消正在执行的 AI 任务，并停止当前后台扫描；原文件、笔记、对话历史、扫描来源与加密密钥不会被删除。再次进入智能模式可继续使用原有配置。

## 私密文件夹

在资料库中点击“私密文件夹”，首次创建 8 至 256 字符密码，以后用密码打开。首页和侧栏都能找到它，纯净和智能模式均可使用。打开后保留普通侧栏、主题和语言，在文件夹内导入、筛选、阅读和记笔记；这里的内容不接入 AI，也不会出现在普通分类或搜索结果中。点击“返回资料库”、其他侧栏分类或“锁定文件夹”即可锁定；`Ctrl Shift L` 同样可以锁定。重启后需重新输入密码。

私密文件夹保存独立的加密索引，不会自动移入普通资料库已有条目。请先打开文件夹，再拖入文件或点击导入。普通资料库中已收录的同一原文件不会自动隐藏。

也可以在普通资料库选择“移入私密文件夹”。v0.8.1 会先保存加密记录、现有封面与关联摘录，再清理这些资料在普通库中的记录、正文索引、回顾条目、空间成员关系和相关撤销字段。混合操作中其他资料的修改保留；只包含被移入资料的操作变成不可撤销的占位记录。目标已存在同一文件时停止移动，不覆盖任何一边的笔记。清理失败会报错并保留仅含随机 ID 的待办记录，下次启动先重试，不能将失败提示视为已完成。

普通 SQLite 会开启安全删除、重建全文索引并压实数据库，再重建 `.bak`。旧 `library.json`、`.bak` 和 `.pre-0.8.1` 迁移快照只改写目标记录，保留其他资料和顶层元数据；旧封面与持久译文副本会删除。处理过程中请勿强制关闭程序。

实现同时处理数据库页和全文索引段；SQLite 分别说明了 [PRAGMA secure_delete](https://www.sqlite.org/pragma.html#pragma_secure_delete) 与 [FTS5 secure-delete](https://www.sqlite.org/fts5.html#the_secure_delete_configuration_option) 的作用和限制。

**这不等于追溯加密或安全擦除整台电脑。** 原文件、自动导入排除列表中的原路径、此前的独立 Agent 对话 / 任务记录、无法按资料 ID 追溯的 AI 摘要缓存、加密文件版本、导出和用户自行复制的备份不会随之迁入私密库。应用不会清空无关缓存或删除整份旧备份。文件系统快照、SSD 历史块、系统或外部应用缓存也不在保证范围内。需要防止设备离线取证时，应同时使用系统磁盘加密。

离开窗口、最小化或闲置 5 分钟会自动锁定。系统文件选择框期间暂缓锁定；正在导入时先遮挡私密内容，待操作完成后锁定。锁定保存当前笔记与进度，清除界面内容、释放解密密钥、清理浏览器磁盘缓存，旧私密媒体链接失效。

`data/private-vault/` 的索引与笔记使用 PBKDF2-SHA256（210,000 次、独立随机盐）派生密钥，以 AES-256-CBC 加密并使用 HMAC-SHA256 校验后解密；每次保存使用随机 IV。封面同样加密。密码不写入文件，连续失败后限制尝试频率。密码丢失无法恢复。

**保护范围是 kok 的索引、笔记与封面。原始视频、照片、文档仍在原路径，不会被加密、移动或隐藏。** 导入字体与使用系统应用打开文件也不属于加密保护；系统播放器和其他软件可能保留自己的历史。私密文件夹不能代替磁盘加密，也不能抵御已能读取进程内存的程序。

## 私密备份与恢复

私密文件夹 → 设置 → 导出资料库，会生成 `.kokvault` 备份，内含 `vault-info.json`、加密的 `library.vault` 和 `thumbs/*.sealed`，不包含原始文件、AI 密钥或 WebView2 缓存。备份仍需原密码，不能脱离原始文件路径播放内容。

当前未提供一键恢复按钮。手动恢复时，关闭 kok，先备份现有 `data/private-vault/`；将 `.kokvault` 作为 ZIP 解压，把其中内容放入该目录，再启动并用原密码解锁。不要混合不同私密库的元数据、索引或封面。若迁移到新电脑，原文件也需单独恢复到相同路径。

应用不会将用户文件、密码或模型配置上传到 GitHub。发布包从干净文件清单构建并检查私密文件及密钥模式。
