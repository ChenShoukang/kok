# v0.8.1 · 模块契约与工作记录

[English](MODULES_0.8.1.en.md) · [架构](ARCHITECTURE_0.8.1.md) · [当前覆盖范围](WAREHOUSE_0.8.1.md)

原生 catalog 是唯一能力清单。设置列出模块、资料类型、分面、工具、权限与开关；界面契约双向核对。所有媒体导航使用声明。停用模块会隐藏导航、命令和 Agent 工具，并拒绝直接原生调用。编辑器先保存；有独立原生预览窗口时要求先关闭对应窗口。

ActionSpec 必须声明 schema、Requires、读写类型。缺失声明、重复动作 / 工具 / 能力及冲突的字段归属都会注册失败。兼容动作继续执行原领域校验，部分兼容 schema 暂时允许附加字段。Need.Ai / Network 受纯净模式限制，Need.NormalLibrary 拒绝私密库；取消动作无需启动 AI。

Operations 保留来源、目标、前后值、资源、状态与撤销关联。整批先检查，再应用；重复确认使用同一持久化操作 ID。撤销保留后续编辑，包括外部程序改动的真实文件。撤销创建只移除索引，不删除源文件。历史从 SQLite 分页读取；8 MiB 是单个操作上限，不是全部历史上限。

Jobs 聚合 Agent / 下载的持久化提供者与加密管理记录，区分可续跑和只能取消的任务。进程重开保持暂停或取消。配方检查点保存上一步结果与操作 ID，配方或来源改变后要求重新预览。密钥不进入渲染器。

Agent 的实现通过 AgentUi 契约访问，内部函数不发布到全局。flush 在停用前保存草稿；重新启用重新读取原生任务状态，保持暂停。会话保存串行、同内容合并，停止任务会等待当前会话保存。

文档与 PPT 对外使用 DocumentUi / PresentationUi，内部全局定义已收进模块。新建对话框只展示已启用模块支持的格式，全部关闭后隐藏入口并停止处理 Ctrl+N。catalogChanged 在清单更新和模块生命周期完成后发出；工作区关闭时，共用查看器隐藏其笔记与上下文 AI。

事件使用 Kok.on；导航和卡片是声明，检查器由模块贡献分区，关窗快照通过稳定的具名管道组合。旧实现和层叠样式仍有迁移工作，请以当前覆盖文档为准，不能把注册骨架视为整份规划已全部完成。
