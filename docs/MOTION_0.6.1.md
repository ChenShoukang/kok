# v0.6.1 · 轻量交互动画

[English](MOTION_0.6.1.en.md) · [文档](README.md)

本文记录 v0.6.1 开发阶段的修订，现已包含于 v0.6.2。新增动画集中在状态变化，不给正文、整个资料库或拖动中的窗口增加入场效果。

| 位置 | 反馈 |
| --- | --- |
| 设置分类 | 固定窗口尺寸，内容短距离交接，选中下划线连续移动；快速切换清理旧画面 |
| 阅读布局与侧栏标签 | 背景随单页、双页、滚动和工具标签移动，按钮位置不变 |
| 收藏、书签 | 保存后图标轻微缩放；文字节点和阅读位置保留 |
| 菜单 | 短距离淡入淡出；关闭时立即停止接收点击，结束后移除 |
| 笔记、翻译与 AI 侧栏 | 小幅位移和淡入；笔记快速开关以最后一次操作为准 |
| 照片、消息 | 缩放与旋转平滑过渡，实际拖拽保持即时跟随；消息轻微淡入 |
| 笔记工具 | 链接 / 反向链接 / 大纲交接；补全列表原位更新，输入不重复弹出 |
| 知识图谱 | 后台算好布局再淡入；筛选保留位置，节点拖动后停在原处；单帧循环驱动阻尼缩放和关联高亮 |

菜单和反馈约 100～180 毫秒，侧栏约 220 毫秒，弹窗入场 230 毫秒。普通弹窗使用位移 / 透明度，正文不随整窗反复缩放；原生预览保留点击位置展开，幅度缩小到 1.5%，重新获得焦点不重播。文档准备好后开始一次入场，较慢读取才显示加载过程。遮罩只改变透明度，避免同时插值模糊滤镜。新的动画会在移动、缩放窗口、页面隐藏或系统开启“减少动态效果”时结束或跳过，最终状态仍会应用。

图谱缩放从当前视图接续，保留速度，不跳到上一次终点；滚轮以鼠标位置为中心，小幅触控板输入即时跟随。筛选不重新缩放整个图，已有坐标保留，关闭窗口停止全部计算和绘制。侧栏只由一套动画控制，消除原先 CSS transition 与脚本动画争抢状态的现象。

同时纳入原生窗口修正：移动不触发阅读重新分页；缩放时正文宽度实时适应，结束后按文字锚点校准；PDF 缩放保留现有画布，完成新渲染后替换。具体原因见[窗口修正记录](WINDOW_DRAG_FIX_0.5.1.md)，已包含于本版本。

参考 [AutoAnimate](https://github.com/formkit/auto-animate/blob/master/src/index.ts) 的局部布局过渡与中断管理，以及 [Radix Presence](https://github.com/radix-ui/primitives/blob/main/packages/react/presence/src/presence.tsx) 的退出完成和显隐状态管理。实现使用浏览器原生动画；未复制组件源码或加入动画依赖。

本次重做进一步参考 [Sigma.js Camera](https://github.com/jacomyal/sigma.js/blob/main/packages/sigma/src/core/camera.ts) 的相机取消与接续，以及 [Svelte transitions](https://github.com/sveltejs/svelte/blob/main/packages/svelte/src/transition/index.js) 的短位移 / 透明度交接。相机使用自行实现的临界阻尼积分；无新增运行时。

验证使用独立资料库和静音窗口，覆盖快速反向切换、菜单关闭与重开、侧栏互斥切换、键盘退出与焦点、减少动态效果、浅深主题，以及原生快速移动、缩放、最大化与取消。测试不读取个人 API 配置，也不发送 AI 请求；这些检查不能代替不同硬件上的帧率评估。

另外修复分页切回上下滚动时残留的分页占位，避免出现多余横向滚动条。边界检查覆盖动画播放中改变减少动态效果、关闭文件清理菜单、照片拖拽和窗口交互期间停用照片过渡。

开发检查：`npm run check`、`npm run check:windows`、`build.ps1`。定向桌面测试：`tools/test-desktop.ps1 -Suites calm-motion` 和 `-Suites window-drag`。两组测试自动生成离线书籍和 PDF 样本，不依赖此前的测试输出，也不扫描用户文件。

`-Suites motion-polish` 额外采样真实中间帧，检查设置尺寸、反向操作的位置与速度连续性、鼠标缩放锚点、节点静止入场、补全不重播、关闭清理和减少动态效果；兼容不同刷新率，按实际时间采样。若已有测试 FFmpeg，可生成隔离示例界面的 WebM，不会下载组件或记录真实个人资料。
