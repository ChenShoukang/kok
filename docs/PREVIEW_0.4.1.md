# v0.4.1 预览版

中文 · [English](PREVIEW_0.4.1.en.md) · [文档目录](README.md)

本版作为 GitHub 预览版提供。启动解压目录中的 `kok.exe`，保留全部配套文件。原有资料库可继续使用；新增偏好和书签保存到当前资料库。

## 外观

默认使用中性白 / 石墨灰，页面、侧栏、工具栏与弹窗共享同一套材质和文字颜色。主图标重新设计为蓝色折页式几何 K，移除圆角底板、渐变高光和厚重阴影。

顶部窗口栏跟随深浅主题与自定义背景，不再显示系统白色标题栏；保留拖动、双击最大化、最小化、还原和关闭。按钮使用 4px 轻圆角，输入框 6px、菜单 8px，以细边框、留白和玻璃材质形成层次，保留悬停和键盘焦点反馈。

整体改用紧凑侧栏与连续页面，分类入口为 44px 小方形，悬停或键盘聚焦显示名称；封面采用不超过 184px 的小方形，悬停或聚焦显示打开、收藏与更多操作，触屏保留操作入口。界面以中性配色、字号层次与分隔线组织内容；书页、相纸、唱片保留轻微拟物质感，按压与浮层使用同一套动效，支持减少动态效果。

默认内置[得意黑 Smiley Sans v2.0.1](https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1)，无需联网或安装到 Windows；完整许可随包提供。设置中仍可切换系统字体、微软雅黑、宋体、楷体或导入自己的字体，已有选择保持有效。

分类图标与缺省封面使用同一套 [Microsoft Fluent Emoji Flat](https://github.com/microsoft/fluentui-emoji) 开源资源，已本地内置并附 MIT 许可；版本、来源与文件校验记录随包提供。

图标使用 Flat 矢量版本，去掉重阴影与高光；悬停以透明度变化反馈，按压只作轻微缩放。主图标、启动页和 Windows 程序图标统一使用新的几何 K。深色模式使用低饱和、柔和的图标颜色；导入按钮和主要按钮使用深色底。

侧栏的分类、收藏、最近打开、整理、下载与设置统一使用 24px 图形框、44px 点击区域和 6px 行间距；按实际图形边缘将可见长边对齐到 20px。缺省封面使用 96px 图形框、80px 可见长边，保持原始比例并居中；修复了旧分类尺寸和视频占位图标的定位冲突。列表图标框 24px，顶部与查看器的操作图标 18px。

## 文档与读书

- **目录**：输入章节名称筛选；PDF 使用文件本身提供的目录，没有目录时显示提示。
- **全文搜索**：左侧选择“全文搜索”，逐章或逐页检索，点击结果定位；最多显示 200 个结果，可停止并返回搜索前的位置。`Ctrl Shift F` 打开全文搜索，原有当前章节搜索继续保留。PDF 需要可选文字，不提供 OCR。
- **书签**：工具栏添加当前位置，左侧“书签”中打开或删除。PDF 保存页码，文字阅读保存章节和位置；普通与私密文件夹各自保存。
- **排版**：工具栏“阅读排版”调整字号、行距、字距、段落留白、正文宽度，以及连续滚动 / 左右分页。分页时方向键、Page Up / Down 与空格翻页；输入框操作不会被抢占。
- **续读与专注**：底部滑块跳转阅读进度，重新打开恢复位置；“专注阅读”收起目录并放大阅读空间，再点一次退出。
- **笔记**：原有下划线、荧光、想法和文档插入文字继续保留。书签页可导出 Markdown 笔记与书签；HTML 阅读副本仍可使用。导出 Markdown 是明文，即使内容来自私密文件夹。

文字排版适用于 EPUB / TXT / DOCX 等现有正文阅读；PDF 保留页面布局。原文件保持不变。功能思路参考 [hectorqin/reader](https://github.com/hectorqin/reader)，代码和界面由 kok 独立实现；本版继续使用本地资料库。

## 照片缩放与自由裁剪

- 预览与编辑画布都支持滚轮缩放；放大后可拖动查看。预览中双击切换放大 / 适应窗口，`+` / `-` 调整缩放，`0` 适应窗口；编辑区也有缩放与适应按钮。
- 点击 **编辑照片 → 裁剪与方向 → 自由裁剪**。在图片上拖出选区，可移动选区、拖动四角和四边调整；也可锁定常用比例。应用后再另存为新照片。
- `Enter` 应用裁剪，`Esc` 取消本次裁剪；方向键微调选区，Shift 加快调整。裁剪支持撤销 / 重做，旋转或翻转后的选区也按当前看到的位置处理。
- 裁剪框和网格不进入导出图，原片不变，输出长边仍最多 4096 px。裁剪尚未应用时保存按钮暂时禁用，先应用或取消即可。

## 视频下载

切换至**智能模式 → 视频下载**。由 kok 在本地解析和管理下载，不需要 AI 密钥，也不调用外部解析服务；纯净模式及私密文件夹阻止联网下载。

1. 粘贴网页、音视频文件直链、M3U8 或 MPD，每行一个，一次最多 20 个。
2. 选择最佳 / 最高 1080p、720p、480p 或仅音频。画质只在来源提供多档时生效，不进行画面缩放转码。单个链接可先解析，看到多个资源时手动选择。
3. 可勾选保存网页已有字幕。支持页面公开的 SRT / VTT，保存在媒体旁边；不进行语音识别。字幕保存失败不影响已完成的媒体。
4. 开始下载；支持队列、暂停、继续、重试、取消、自动入库及打开文件夹。清理历史不删除文件，退出后手动继续。旧记录和下载文件保留。

**三站适配与登录**：已接入 B 站普通视频 / 分 P、YouTube 和抖音专用解析。B 站和 YouTube 会分别下载视频与音轨，再由 FFmpeg 合并，避免高清无声。打开 **站点与登录**，可在官方页面手动登录、导入自己导出的 Netscape cookies.txt，或清除已保存信息。会话按站点隔离，使用 Windows DPAPI 加密，仅限当前 Windows 用户恢复，不发送给 AI；已保存会话不保证持续有效，不扩大账号已有权限。

B 站 / 抖音若返回脚本校验页面，可点击 **网页辅助解析**：在静音官方页面手动打开目标视频、完成所需验证，再点击“使用检测到的资源”。此入口使用隔离的临时浏览器，不暴露 kok 的应用桥接；只有你选择资源后才保存相应站点会话。解析结果在内存中有效 10 分钟，重启后或过期后需重新解析并添加任务。YouTube 下载暂停恢复时会重下；分轨任务尽量复用已完成轨道及未完成片段。

**网页范围**：识别 HTML video / audio / source / track、Open Graph、JSON-LD 与常见静态播放器配置中的公开链接，可查找有限层数的嵌入播放器。普通解析不运行网页脚本，也不会自动读取你现有浏览器的 cookies。三站适配和手动辅助解析仍可能受到网络、验证码、站点风控或权限限制，不保证所有视频可用；直播、DRM、付费权限绕过与整张播放列表不支持。网页没有公开媒体时会给出原因，可改用媒体直链。一次解析处理至多 4 MiB 网页和有限数量的媒体候选。

**文件直链**：使用服务器 ETag / 修改时间及 Range 安全续传；文件变化、缺少校验或无效范围时重新下载并说明。支持中文文件名、重定向、未知总大小和大文件，不覆盖原有同名文件。

**媒体组件**：分段合并和视频转音频需要 FFmpeg / FFprobe。点击“一键安装”，下载固定的 9.0.2 Gyan Windows 构建，约 109 MiB（安装后两个程序合计约 201 MiB）。核对压缩包及两个程序的 SHA-256，保留许可；支持进度、取消和自动识别，也可选择已有的成对安装。基础包不包含它们。

**M3U8 / DASH**：支持常见未加密 HLS 主 / 媒体清单、静态 DASH 及相对分段地址，选择可用视频档位和音轨，以流复制合并为 MP4（仅音频为 M4A）。分段任务显示时长进度，**暂停后恢复会重新下载**。格式需能封装进 MP4 / M4A；复杂嵌套、直播、加密 / DRM 清单暂不支持，清单不能读取本地文件。仅音频导出尽量复制 AAC / ALAC；其他音轨转换为 AAC。

完成的媒体进入普通资料库；字幕与原始链接、资源地址留在本地。下载历史是普通明文数据，不发送给 AI，不属于加密私密存储。播放能力仍受当前播放内核支持的实际编码限制。

组件与许可：[FFmpeg](https://ffmpeg.org/)、[Gyan Windows 构建](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)、[第三方说明](../THIRD_PARTY_NOTICES.md)。

## 开发检查

本轮隔离静音检查通过：原生直链解析、范围续传、文件变化与异常范围、未知大小、大文件元数据、队列与取消；kok 网页解析覆盖 HTML 媒体、Open Graph、JSON 元数据、嵌入播放器、资源 / 画质选择、字幕、音频导出、HLS / DASH、入库、旧组件清理、中英文和小窗口。素材均为本机原创，未使用私人影片、模型服务或外部解析 API；未逐个验证外部视频网站。

此前原生功能、配色、照片、文档和读书已有检查记录。本轮没有重跑所有旧功能。预览发布前审计暂存目录和最终 ZIP，排除模型配置、密钥与私密资料。独立 Windows 10 / 11 电脑验证仍待补充。

三站检查：B 站与 YouTube 的公开视频元数据分别解析出 7 和 8 个资源；未下载完整外部视频。抖音匿名请求遇到脚本校验，未证明可自动解析全部视频；需手动网页辅助或有效会话。已用本机原创素材验证分轨合并、音频导出、站点数据格式与账号界面，并验证加密、域隔离、清除和离线 YouTube 库调用；未使用真实账号完成登录验证。
