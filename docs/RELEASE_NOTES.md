# kok v0.11.2 Preview

第一次打开 kok，可以先用示例做一份笔记。已有项目可以搜索，导出后也能回到项目找到交付文件。

- **用示例试一次**。在空白的 Agent 首页或「我的作品」阅读一行示例，写下下一步，再保存为可编辑的 Markdown。练习在本机完成，无需配置模型。
- **全部项目**。按名称或目标搜索，不受首页最近 24 个项目的展示限制。手动创建的托管文档或 PPT 可以加入项目成果。
- **交付记录**。成功导出后，从项目查看副本的文件名、时间、位置与文件指纹，也可以在文件夹中定位。记录保存在本机。取消导出不会生成记录。
- **中文帮助中心**。按任务找说明，从第一篇笔记到资料生成报告与 PPT，逐步覆盖改稿、恢复和导出。

下载 `kok-0.11.2-win-x64.zip` 和随附的 `.sha256`。校验后完整解压，运行 `kok.exe`。

## English

Try an example on the empty Agent or My works screen to save an editable Markdown note locally. Search older projects by name or goal, add existing managed work to a project, and find its exported copies by file name, time and location. Export history is stored locally.

Download the Windows x64 ZIP and its SHA-256, extract the full folder and run `kok.exe`.
