# 智能整理

[English](SMART_LIBRARY.en.md) · [文档索引](README.md)

左侧点击“智能整理”，进入文件夹扫描与 AI 归纳页面。界面支持中文 / English、浅色 / 深色、小窗口布局及减少动态效果的系统偏好。

1. 点击“发现文件”旁的加号，选择你想收录的文件夹。首次立即扫描；之后 kok 打开期间每 45 秒查找新增文件，子文件夹也会扫描。
2. 可以暂停、恢复或移除扫描来源，也可以立即扫描或停止正在进行的扫描。隐藏目录、系统目录、链接目录及 kok 自身数据会跳过；无法访问的目录会在页面提示。
3. 在“AI 归纳”中配置现有 AI 服务，选择未整理文件或重新分析全部文件。每次最多处理 50 个文件，可取消勾选不想分析的文件。
4. 默认只发送文件名、格式、大小和所在文件夹名称，不发送完整路径、文件正文或媒体。可选文字节选模式会额外提取最多 1200 字的正文；仅支持不超过 2 MB 的 TXT、MD、MARKDOWN、CSV、LOG、JSON、DOCX、EPUB。其他格式仍仅使用文件信息。
5. 点击“开始归纳”，等待分类、标签、摘要预览。取消不应用结果；预览中可取消勾选，再点击“应用所选分类”。AI 分类会成为左侧资料库分类，相同输入的结果会在本机缓存。
6. 在普通文件菜单中点击“编辑分类与标签”，可修改分类、最多 8 个标签及摘要。搜索支持分类、标签和摘要。

文件始终保留原位，不会移动或改名。自动扫描按完整路径去重；从资料库移除的文件不会在下一次扫描中重新出现，手动导入可以恢复。暂停或移除来源不会删除已收录文件。

AI 归纳共用“AI 翻译”里的 API 地址、模型与加密密钥；分类语言跟随界面语言。用户密钥只保存在本机 `data/ai-settings.json`，使用当前 Windows 账户的 DPAPI 加密。默认不会自动向 AI 发送新增文件，只有点击开始归纳才请求接口；费用按所选服务商规则计算。根据文件名推测的结果可能不准确，请在预览后应用。未进行图片内容识别、语音识别、视频画面理解或 PDF OCR。

## 时间、类型与自定义

智能整理默认显示“时间顺序”，按文件修改时间从新到旧分组；“内容类型”按视频、照片、音乐、文档、读书分开显示。这两种方式无需 AI。自定义方式可选中文件，批量归入现有或新建分类；原文件保持原位。“AI 归纳”仍可独立使用。

## 内容 AI 对话与媒体窗口

视频、文档和电子书右上角的“AI 对话”打开右侧助手，可总结、连续提问、讨论选中文字，并把回答保存为想法。每个文件分别保留最多 40 条、合计约 16 万字以内的对话消息；请求仅带最近 12 条历史。AI 共用已配置的 API，不会自动请求。

可选择当前章节 / PDF 当前页、全文或字幕范围，勾选是否附带笔记与划线。视频默认读取播放位置前后 90 秒的已载入文字字幕；可使用全部字幕，或额外发送当前画面的压缩 JPEG（需要模型支持图片）。没有字幕时可用当前画面提问，但这不等于理解整段视频。全文超过上下文预算时选择相关节选，较长 PDF 最多读取前后各 20 页；范围会标明“节选”，扫描 PDF 仍需要 OCR。对话中途停止不保存半截回答。

视频与照片读取实际像素尺寸，预览窗口随横屏、竖屏、方形和照片旋转调整，支持右上角切换自适应 / 铺满窗口，不改变原文件。
