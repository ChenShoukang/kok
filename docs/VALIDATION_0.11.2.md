# v0.11.2 Preview 验证

本版验证两个流程。[示例入门](help/getting-started/first-work.md) · [项目搜索与交付记录](help/works/continue-editing.md#项目搜索与交付记录)

| 验收项 | 检查方式 |
| --- | --- |
| 首次体验 | 打开或取消示例不创建文件。保存后得到可编辑的 Markdown，能从「我的作品」再次打开，任务记录保持原样。 |
| 项目搜索与关联 | 建立 25 个项目，确认较早项目离开首页后仍能被搜索。手动添加的成果立即出现在项目中。 |
| 交付记录 | 使用真实 Windows 保存对话框取消、导出 DOCX 和 PPTX 并回读。核对两份文件的位置和 SHA-256。确认取消不写文件或记录。 |
| 持久化与私密隔离 | 重载资料库后读取交付记录，检查项目范围。把副本移入私密文件夹后，普通项目隐藏对应记录，磁盘文件仍在。 |

发布前的开发构建通过 918 项原生测试及四套桌面验收（作品导航、完整创作、Agent 首页和语言切换）。桌面验收使用真实 WebView2 与隔离资料库，创作任务使用本机模型夹具。新手完成时间和真实模型质量需要独立试用。

正式包由 GitHub Actions 在 Windows 2022 和 2025 上重新构建，经过原生测试、归档隐私检查和解压后的 26 套桌面验收。下载时以对应 Release 附件的 SHA-256 为准。
