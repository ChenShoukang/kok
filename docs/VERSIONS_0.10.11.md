# 版本与局部改稿（v0.10.11）

[项目首页](../README.md) · [创作项目](CREATIVE_PROJECTS_0.10.10.md) · [本次验证](VALIDATION_0.10.11.md)

本版把“改一段、看差异、回到某一版”做成日常操作：作品的历史版本可以浏览、对比、恢复；手动保存前先看差异；选中文字或幻灯片就能让 Agent 只改这一处。

## 版本面板

在 kok 新建/编辑的文档（Markdown、TXT、DOCX）编辑器里，标题栏出现 **版本** 按钮：

- 列出**当前版本**与历史版本（时间、标题、来源、状态）；历史来自每次字节变化的保存，最多列 100 条。
- 点任一版本 → 显示该版本与下一版的**逐行差异**（`+N/−M`、旧行/新行着色）；文本不可用的格式（如 DOCX）显示前后 hash 与大小。
- **恢复此版本** → 二次确认（目标版本 vs 当前时间）→ 恢复；恢复本身会生成一条可撤销的新操作，恢复后编辑器正文与保存状态立即同步。
- 版本记录损坏/缺失的条目会标记为不可用；私密文件夹不保存版本，也不会出现版本面板。

## 手动保存前差异预览

- 覆盖保存（保存按钮或 Ctrl+S）且内容有变化时，先弹 **保存前确认**：已保存 → 将保存的逐行差异与 `+N/−M`；点“取消”不写文件、保持未保存状态，点“确认保存”才写入。
- 自动保存（停止输入约 700ms 后）保持不变，不会每次弹窗；失败重试与恢复草稿逻辑不变。

## 选中片段 → 让 Agent 改这段

- 在文档中选中一段文字，“让 Agent 改这段”按钮启用；点击后 Agent 会收到：文档名与 ID、选中的原文（引用块）、以及“只修改这一段、保留其他内容、用 `replace_document_text` 且 old_text 取原文唯一片段”的约束。
- 只把提示词放进输入框并带上文档上下文，**不会自动发送、不会新建任务**；你可以补充要求后自己发送。
- 选择为空、超过 2000 字、非智能模式、有未保存/未完成写入时都会提示，不会误操作。

## 选中幻灯片 → 让 Agent 改这页

- 演示文稿查看/编辑工具栏新增 **让 Agent 改这页**：提示词包含演示 ID、当前页码/总页数、当前页标题与文字（≤1500 字，图片只计数量）、以及“只改第 N 页、其他页保持原样、建议使用 `edit_presentation` 并注明页码”的约束。
- 同样只填充输入框并带演示上下文，不自动发送；会先按现有语义保存草稿，避免让 Agent 改到未落盘的内容。

## 边界

- 版本恢复是**补偿式新操作**：保留完整历史、可再撤销；与审批/证据/撤销安全模型一致，不绕过任何确认。
- 差异预览在本机计算（JS LCS，行数与字符数有上限），不发起模型请求。
- 自动保存不弹 diff；DOCX 版本只支持字节级恢复与 hash 对比，文本 diff 需要可提取文本。
- 本轮未做命名检查点、分支/章节级版本视图与 PPT 版本对比，属于后续迭代。
