# v0.8.1 · 模块化资料仓库

[English](WAREHOUSE_0.8.1.en.md) · [架构](ARCHITECTURE_0.8.1.md) · [模块契约](MODULES_0.8.1.md)

当前为本地开发预览，未向 GitHub 发布。以下按代码与测试列出实际覆盖，兼容层清理不算完成。

| 部分 | 已实现 |
| --- | --- |
| 模块 | 所有业务动作经过原生注册表；窄上下文、声明权限和参数、字段归属、模块开关。媒体等领域使用服务端口，旧 switch 已改为显式处理表 |
| 界面 | 所有类型导航由模块声明，壳层统一渲染。命令、右键和选择操作共享 Capability；事件和关窗快照通过模块扩展分发 |
| 存储 | SQLite 核心资料、分面、links、空间对象、操作记录、日回顾和派生缓存。旧 JSON 原样保留，迁移副本先校验再切换 |
| 私密文件夹 | 内存 SQLite 加密保存，无明文 SQLite / WAL；本地正文检索同样加密。原文件仍位于原路径，不会因此被加密 |
| 全文搜索 | 文件名、笔记、标签、批注、生成字幕、视频大纲和托管文档正文；可建立 TXT / Markdown / CSV / JSON / LOG / HTML / DOCX / EPUB / PPTX 与本地字幕索引。FTS5 trigram，短查询使用包含检索；后台查询不在范围筛选前截断结果，已验证 6,001 条资料 |
| 操作历史 | 通用资料修改、书签、批注、草稿、分类、导入移除、空间、摘录和配方。分页读取，兼容导出包含全部历史，不自动删除旧历史；撤销前比较当前值。托管文档可恢复真实文件字节，保留外部修改 |
| 活动 | Agent、下载、翻译、扫描、导入、语音、导出与内容任务聚合；状态和任务参数在本机加密保存。可续跑任务才提供暂停 / 继续，重开不会自动执行 |
| 今天与检查器 | 继续阅读 / 播放、最近摘录、后台活动。资料详情、笔记、反向链接、媒体分区及上下文 AI。草稿加入关窗保存，切换私密文件夹前保存 |
| 摘录 | 文字范围、视频 / 音乐时间段、照片区域；可回到来源，加入空间、拖入笔记或 PPT。Agent 可读取、提议创建摘录及用摘录写稿 |
| 空间与集合 | 混合资料和摘录，网格 / 画布 / 时间线 / 图谱。图谱共享 Canvas 和后台布局，最多显示 500 个节点；智能集合按保存的条件动态查询 |
| 配方 | 逐字段编辑、资料选择、步骤排序、四种模板和整体验证；一次确认后运行。输出进入操作历史；来源变化会阻止继续。AI 摘要有本地缓存、输入估计和输出上限 |
| 回顾 | 按天记录打开与进度变化，重开后保留。可保存为本地 Markdown 笔记 |
| 查看器 | 共用查看 / 编辑 / 笔记 / AI 页签；F8 切换工作与沉浸，按资料类型记忆。新界面支持中文与 English，沿用用户主题和得意黑默认字体 |

图谱、反向链接和空间关系读取同一个 links 表。解析器负责把正文引用更新为关系行，不另存一套仅供界面的笔记关系。

Agent 会话、渲染和任务交互已从三个全局脚本迁入 `agent-runtime.mjs`，其他模块通过 `AgentUi` 接口调用。原来的 57 个顶层定义收进模块作用域；停用前保存草稿，重新启用只恢复暂停状态，不自动重放任务。会话保存串行执行，相同内容不重复落盘，失败后保留原记录并可重试。

文档新建 / 自动保存和 PPT 查看 / 编辑 / 草稿也已迁入真实 ES modules，通过 DocumentUi / PresentationUi 调用，不再加载原有两个全局脚本。PPT 草稿串行保存，关闭时补存写入期间的新修改；失败保留已保存版本并允许重试。新建格式、入口和 Ctrl+N 跟随模块开关。

共用查看器保持按钮节点和键盘焦点，方向键 / Home / End 导航工具栏，空格与 Enter 不再被翻页 / 播放快捷键抢占。侧栏按实际顶栏高度定位，宽窗口预留媒体空间，窄窗口覆盖显示。工具栏与照片布局统一由 viewer-shell.css 负责，删除旧文件里的竞争规则；仍保持 42 份样式源和 9 个运行时包。

工作区、摘录交互和共用查看器已迁入真实 ES modules。42 份样式源按原有层叠顺序生成 9 个运行时包，共用设计 token；这减少运行资源，不等于旧组件样式已经全部合并。摘录、空间和智能集合每页最多渲染 120 张卡片，图谱独立保留 500 节点上限。

Agent 可调用字幕模块自己的异步工具；请求继承任务取消，结果进入活动和操作历史，重复调用复用回执。使用已配置的本地引擎或语音 API，不会自动安装模型。字幕引擎本轮只通过模块端口模拟验证，未运行真实语音识别。

尚未完成的整体验收包括：将所有旧实现完全拆成独立 ES modules；继续收敛多代 CSS 与 Classic / Graphite 组件差异；更完整的跨窗口与大型资料库压力验证（已覆盖 2,500 条摘录分页、6,001 条资料的 SQLite 检索与范围筛选，以及大小窗口，但尚非长时间、海量磁盘资料压力测试）。具名扩展注册不等于兼容实现已全部移除。

格式边界：扫描 PDF 仍需 OCR；旧 Office、DRM 电子书和不支持的媒体编码没有新增解码能力。PDF 阅读与标记继续使用现有本地查看器，本轮没有承诺扫描件全文检索。导入取消保留已经提交的条目和原文件；不可续跑的导出 / 交互任务只提供取消。

已验证的场景包含旧 JSON 保留、中文短词检索、操作冲突与真实文件撤销、私密索引、配方离线运行及过期来源、照片区域摘录、拖放与草稿保护。真实文件测试对用户提供的 11 份资料做只读验证。测试只证明实际覆盖的场景，完整规划尚不能标成正式验收完成。

运行包不需要 Node.js。SQLite 是内置原生库，Acorn 仅用于开发检查。测试资料、密钥、数据库、私密数据、加密版本文件和测试输出均排除在包外。
