# 窗口拖动与缩放 · 本地修订

此修订基于 v0.5.1，尚未覆盖 GitHub 安装包。

- 区分原生窗口移动和尺寸变化。普通移动不重新分页、不重载阅读字体，也不额外播放焦点淡入 / 位移动画。
- 书页实时跟随窗口尺寸，不再冻结旧宽度；结束后按正在阅读的文字校准位置。
- 取消拖动、丢失鼠标捕获或切走窗口时清理交互状态，避免持续停留在“正在缩放”。
- 拖动时保持工具栏材质一致、保持工具栏可见。独立视频 / 照片窗口不再重复执行内嵌弹窗的自适应动画。
- PDF 缩放期间保留旧画布并同步适应宽度，新画面画好后再替换；窄窗工具保持单排，可横向滚动。
- 翻页动画临时使用直接滚动，避免浏览器平滑滚动与自定义动画叠加。

验证使用隔离静音资料库、合成书籍与 PDF、原创媒体。原生辅助程序连续移动 / 缩放窗口，同时逐帧采样，而非只检查停止后的状态；覆盖最大化 / 还原、中途取消、按钮边界、阅读文字位置、工具栏材质与 PDF 画布保留。另检查 PDF 选字、高亮 / 下划线坐标及窗口关闭恢复。未调用模型或读取个人文件。

本机回归中，普通移动触发的完整分页重排为 0；连续缩放及最大化后各校准 1 次；PDF 在缩放期间不重绘，结束后重绘 1 次。实际表现仍受硬件、屏幕缩放与文档复杂度影响。

窗口消息处理参考 [Microsoft WebView2 示例](https://github.com/MicrosoftEdge/WebView2Samples/blob/main/SampleApps/WebView2APISample/ViewComponent.cpp) 与 WinForms 窗口行为，保留系统窗口管理与原有内核。
