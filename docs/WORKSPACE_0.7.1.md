# v0.7.1 · 有范围的图谱与拟物资料库

[English](WORKSPACE_0.7.1.en.md) · [返回](../README.md)

本地预览，暂未发布。保留现有影音、照片、文档、阅读、编辑、翻译与字幕功能；应用和 Windows 文件版本统一为 v0.7.1。

## 图谱用于整理资料

顶部选择全部资料、分类、收藏或手动选择。展开“筛选与保存范围”可叠加分类、标签、类型和加入日期，限制显示 100 / 250 / 500 个节点。单个节点仍可查看一层、两层关联。先筛选真实资料，再生成标签和未创建笔记节点，隐藏资料不会成为跨范围的连接桥。

输入名称保存范围，之后从“已保存范围”恢复；最多保留 12 个。手动范围保存文件 ID，资料移除后不会被其他同名文件替代。搜索、筛选和保存范围均在本地进行，纯净模式也可用。

## 内置 AI 任务与用量

智能模式打开“AI 分析”，选择下列内置任务。这里的任务是版本化提示词与本地处理流程，不执行模型返回的代码，也不安装工具或启动多轮代理。

| 任务 | 处理方式 |
| --- | --- |
| 找关联 | 依据所选正文或笔记提出少量关联，显示来源和理由；虚线仅为建议，不改写原文或伪造双向链接 |
| 总结范围 | 简短总结当前资料，保留引用，不额外生成关联 |
| 自定义提问 | 只根据当前范围的可读证据回答问题 |

1. 选择 1–24 份资料，找关联至少选 2 份。超过上限会提示缩小范围，不会悄悄发送前 24 份。
2. 点击预览。本机读取正文、笔记和划线，去除重复片段，按问题挑选节选；不发送本地路径，不自动联网。
3. 检查“发送预览”，再点分析。只发送列明的节选。无可读正文或笔记的资料会跳过；图片、PDF 画面和视频画面不在此流程中识别。

| 用量 | 上下文字符上限 | 回答 token 上限 |
| --- | ---: | ---: |
| 省用量 | 6,000 | 900 |
| 均衡 | 14,000 | 1,400 |
| 更多上下文 | 24,000 | 2,000 |

这不是精确费用估算；供应商分词、缓存计费和价格不同。短提示词不保证模型答对，因此仍校验来源 ID、重复关联、越界和自关联。返回不完整或格式无效时不会保存为有效结果，也不会自动重试产生额外请求。

相同来源节选、任务、问题、语言、模型配置和用量可复用本地结果，最多保留 12 份结果。资料变化后需要重新预览；切换范围、关闭窗口、改为纯净模式会取消当前任务，迟到回答不能恢复旧界面。可将分析保存为 Markdown 笔记，保留引用与资料链接。

私密文件夹仍禁止 AI 和知识图谱，不会继承普通资料库的分析记录。

## 统一的拟物形态

- 书：纵向书本、书脊与纸边；文档：更扁的纸张与折角；视频：16:9 横向画幅；照片：相框；音乐：专辑或唱片。
- 私密文件夹使用居中的保险柜矢量图，清除此前继承的位置偏移。列表仍保留实际缩略图和格式标识。
- 56 种可收录格式都有独立的格式印记；字幕和字体也有对应图标。格式文字、类别形状和受控颜色共同区分类型。它们不意味着新增解码器或提高 Office 排版还原能力。
- 悬停或键盘聚焦时轻微抬起图标细节、打开场记板或改变唱片线条；不持续循环。窗口拖动缩放、页面隐藏或减少动态效果会结束新增动画。
- 小窗口中 AI 助手占用完整工作区，使用“返回图谱”切回，避免把图和表单压成不可用的小块。

资料库与图谱未新增运行依赖、字体、解码器或大贴图；图标为原创 SVG / CSS，格式图标缓存有上限。动画沿用浏览器原生能力，图谱由现有 Worker 布局；收敛后停止计算和重绘。PPTX 编辑使用单独按需加载的导出组件，见[演示文稿与就地 AI 编辑](PRESENTATION_AGENT_0.7.1.md)。

## 参考与实现范围

参考下列项目的交互和设计思路，未复制整套代码或引入其运行时：

- [Logseq 图谱源码](https://github.com/logseq/logseq/blob/master/src/main/frontend/components/graph.cljs)：可保存的范围、标签与深度。
- [Kavita 封面设置](https://wiki.kavitareader.com/guides/admin-settings/media/)：适合阅读资料的竖向封面比例。
- [Khoj 提示词](https://github.com/khoj-ai/khoj/blob/master/src/khoj/processor/conversation/prompts.py)：依据所选资料作答，引用与回答放在一起。
- [Affect UI](https://github.com/flohoeller/affectui)、[Radix Themes](https://www.radix-ui.com/themes/docs/components/button)：一致的按压、选中、禁用状态与安静的交互反馈。
- [VSCode Icons](https://github.com/vscode-icons/vscode-icons)、[Fluent System Icons](https://github.com/microsoft/fluentui-system-icons)：完整格式覆盖、统一视图边界与类别识别。
- [Remotion 时间插值](https://www.remotion.dev/docs/animating-properties)和[阻尼参数](https://www.remotion.dev/docs/spring)：借鉴时间驱动状态、边界约束与阻尼思路。kok 使用原生 WAAPI 和解析阻尼计算，未打包 Remotion。

测试使用生成资料和本地模拟 API，不读取个人库或使用真实模型额度。覆盖范围交集、保存恢复、预览零请求、真实请求用量、缓存、原文变化、取消、500 节点、快速筛选、拖动中筛选、原生连续缩放 / 最大化、双主题、中英文、紧凑布局和减少动态效果。仍需在更多硬件、DPI 和真实资料上继续验证。
