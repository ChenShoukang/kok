# Agent 概览

Agent 是 kok 的主要协作入口：用一句话说明目标，它在选定的资料范围内搜索、阅读和讨论，需要改动时先交给你确认。第一次使用 Agent，可以从这一页了解它能做什么、从哪里进入。

## Agent 能帮你做什么

- 在选定的资料里查找、对比、总结与归纳。
- 整理分类与标签、补充笔记。
- 新建文档和演示文稿草稿，并继续修改。
- 统计数量、列出清单、查看分类与标签分布。

它不能删除、移动或改写你的原文件，也不代替编辑器；这些操作仍由你在资料库里完成。

## 什么时候不适合

- 需要从零生成可播放的音乐或视频：本版只支持剪辑已有媒体。
- 需要小说作品级的章节与设定管理：尚未提供。
- 需要操作 kok 以外的软件或整个电脑：Agent 只在资料库和已授权的工具范围内工作。

> [!info]+ 需要智能模式
> Agent 只在智能模式下出现。打开 **设置 → 功能 → AI 服务** 完成配置后，才能使用需要模型的任务。纯净模式和私密文件夹不会发送任何 AI 请求。

## 从哪里进入 Agent

- 侧栏选择 **Agent**，直接输入要求。
- 在资料库选中资料后，选择 **交给 Agent**，资料会一并带入。
- 打开一份资料，在右侧 AI 面板选择 **交给 Agent**，把当前内容带到 Agent 页继续处理。
- 在 Agent 中展开 **高级设置**，可以调整资料范围、任务方式和技能。

## 任务方式与范围

- **协作修改**：Agent 可以提出修改，但每项都要你确认后才执行。
- **仅讨论**：只搜索和阅读，不提出修改。
- **资料范围**：整个资料库、仅所选资料或指定文件夹；已添加资料时按所选资料执行。

任务结束时会显示成果卡片，也会留下任务记录，可以打开文档、查看来源或继续修改。统计、列表这类只读问题可以由本地规则直接回答，页面会标注“本地完成 · 未调用模型”。

> [!tip]- 先讨论，再动手
> 不确定资料里有什么时，先用 **仅讨论** 让 Agent 读一遍；确认方向后，再切换到 **协作修改** 执行。
