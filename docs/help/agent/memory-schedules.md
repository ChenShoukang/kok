# 长期记忆与计划任务

Agent 可以记住你批准过的信息，也可以按计划自动开始任务。这两项功能都在 Agent 右上角的 **更多** 菜单中管理。

## 长期记忆

打开 **更多 → 长期记忆**，可以 **新建记忆**、编辑或删除记录，也可以选择 **撤销上次修改**。每条记忆有标题和内容，可以勾选 **仅用于这些资料** 关联当前资料，也能保存为个人记忆；列表会标注 **关联资料**、**个人记忆** 或 **来源已变更**。

- Agent 通过确认卡片提议保存记忆时，你确认后才会写入。
- 记录在本机加密保存，只有当前 Windows 账户可以读取。
- 记忆被当作不可信资料使用，不能授予权限，也不能替代原始证据。

在 **能力与权限** 中开启 **长期记忆** 后，任务才会按需检索少量相关记录；来源资料变化后，相关记忆会停止引用并标记 **来源已变更**。

> [!warning]+ 注意
> 私密文件夹不使用长期记忆。不要保存密码或 API 密钥：这类内容会被拒绝保存，但这不能保证发现所有敏感信息。

## 计划任务

打开 **更多 → 计划任务**，可以按 cron 表达式创建自动开始的任务：

1. 填写 **目标**，写清每次要做什么。
2. 填写 **计划（cron）**：`0 8 * * *` 表示每天 08:00，`*/30 * * * *` 表示每 30 分钟一次。
3. 设置 **每次请求上限** 和 **上下文档位**，勾选 **启用** 后选择 **保存计划**。

列表会显示每个计划的表达式、启用状态和下次运行时间，可以选择 **编辑** 或 **删除**；最多保存 20 个计划。创建计划时会记录当时使用的资料范围。

## 计划任务的边界

计划只负责启动任务，每次运行仍遵循逐项审批、资料范围和请求上限；应用需要保持运行，计划也不会打断正在进行的任务。
