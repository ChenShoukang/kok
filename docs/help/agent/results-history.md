# 成果、任务记录与会话

任务结束后，结果会留在对话里，也会进入任务记录和会话。这一页说明如何找回成果、继续中断的任务，以及会话会保存哪些内容。

## 成果卡片

任务结束时会显示一张成果卡片：状态（**已完成**、**部分完成**、**需要补充信息** 或 **已停止**）、使用资料数和来源引用数。有生成文档时可以选择 **打开文档**；展开 **查看来源** 可以回到引用的资料；选择 **继续修改** 会把要求填回输入框，如果有生成的文档，还会把成果加入资料范围。

只读的统计和列表问题显示 **本地完成 · 未调用模型**，并附相关资料与建议追问，不消耗请求额度。

## 任务记录

打开 Agent 右上角的 **更多 → 任务记录**，可以按时间查看历史任务及其状态。选择一条记录会回到该任务的对话、计划和核对结果；**删除任务记录** 只删除记录，资料和原文件保留。

- **继续任务**：网络或服务中断后从任务记录续跑，已执行的修改不会重放。
- **交接到新任务**：只引用所选的读取结果并附上交接备注，不复制整个会话，发送后才调用模型。
- **执行追踪**：查看每次请求的状态、耗时、token 与费用估算；诊断导出不包含提示词、正文、工具参数和密钥。

## 会话

选择 **会话** 可以切换或删除之前的对话。kok 保留最近 12 个会话，每个会话保留最近 80 条记录；草稿、资料范围、任务方式和用量设置随会话保存。

> [!tip]- 任务可以在后台继续
> 切换到其他区域后任务仍会继续运行；窗口不在前台时，完成或失败会显示托盘通知。也可以在 **资料库 → 资料库工具 → 活动** 中查看进度，并选择 **任务详情** 回到 Agent。

## 停止与重开的规则

任务运行时可以选择 **停止**，剩余待办会保留。关闭或重开 Agent 不会自动重放未确认的写入：待确认的操作会暂停并标为跳过，需要重新发送要求后才会生成新方案。
