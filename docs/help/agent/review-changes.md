# 审查与撤销修改

Agent 读取资料会自动进行，但任何修改都要你先确认。这一页说明确认卡片、批量操作、同类授权和撤销的处理方式，帮助你避免误改资料。

## 修改先确认

在 **协作修改** 方式下，Agent 准备改动时会显示确认卡片，写明操作、涉及的资料和原因；笔记、文档和演示文稿还会附带预览。选择 **执行** 后修改才生效，选择 **跳过** 不做任何改动。卡片完成后可以选择 **撤销**。

读取步骤是只读操作，会自动进行并合并成可折叠的步骤；展开后可以看到实际读取到的结果。已读取来源只列出本机真实读取过的资料，可以选择资料回到原处，也可以展开查看发给模型的节选。

## 批量修改与逐项选择

同一轮出现多项修改时，页面先汇总待确认数量和将要修改的项。你可以全选或取消勾选，选择 **执行所选** 只执行勾选项，或者选择 **全部跳过**。未勾选的项目会继续等待，之后仍可单独执行或跳过。

## 同类授权与任务策略

打开 Agent 右上角的 **能力与权限**，在 **审批策略** 中设置：

- **逐项确认**：默认选项，每项修改都单独确认。
- **本任务同类授权**：符合条件的卡片会出现“本任务内允许同类修改（这些资料，后续最多四次）”；勾选后，同类修改在当前任务内最多自动执行四次。
- **只读免审**：任务只进行只读操作，不提出修改。

> [!warning]+ 注意
> 同类授权只适用于分类、标签和笔记这类修改，且仅限当前任务的这些资料；进入后台、重启应用或修改要求后失效。代码、MCP 外部调用、记忆和子任务始终逐项确认。

## 撤销与冲突

已执行的修改可以在卡片上选择 **撤销**；涉及分类、标签和笔记时，可以展开 **查看修改前后** 对照内容。如果修改后你又手工改过同一内容，撤销会保留当前内容并提示冲突。

新建的文档和演示文稿也可以撤销：文档会从资料库移除，磁盘上的文件仍然保留。**仅讨论** 方式不会提出修改；需要改动时，先切换到 **协作修改** 再发送要求。
