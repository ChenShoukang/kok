# 技能、用量与费用

技能决定 Agent 用哪种方式处理资料，用量与费用设置决定一次任务最多能用多少。这一页说明内置技能、导入 SKILL.md，以及请求上限和费用估算之间的关系。

## 内置四类技能

展开 **高级设置**，在 **技能** 中选择 **自动选择技能**（默认）或 **不使用技能**，也可以指定一个内置技能：

- **整理资料**：按主题归类并建议标签。
- **对比资料**：对比观点与证据，标明来源。
- **读书笔记**：保留出处与个人想法。
- **制作演示**：从资料生成简洁的演示文稿。

手动选择导入的指令技能时，对话里会注明使用的技能名称和说明。

## 导入自己的技能

打开 **设置 → 功能 → 指令技能**，选择 **管理技能**，可以查看内置指令、导入 **SKILL.md** 或删除已导入的技能。SKILL.md 需要 `name` 与 `description` 两个字段，正文写指令；最多导入 20 个。

> [!info]+ 技能只是指令
> 导入技能只会附带文字指令，不会加载脚本、注册系统工具，也不会授予文件、网络或命令权限；每次只发送本次使用的技能正文。

## 请求上限与上下文预算

在 **高级设置 → 用量** 中选择档位：**省用量**、**均衡**、**更多上下文**、**长任务** 或 **超长任务**。档位越高，可用的上下文越多；长文档和长字幕也可能只使用节选。

打开 **用量设置** 可以设置 **请求上限**（1–24 次，默认 6）、**每百万输入 token 单价**、**每百万输出 token 单价** 和 **本次费用上限**。达到请求上限时任务会停下并标注“已达到本次请求上限”，不冒充完成。

## 费用估算与边界

单价与费用上限使用同一种货币，费用上限为 0 表示关闭费用拦截。任务会按保守估算在请求前检查额度，额度不足时不开始下一轮；费用只是按你填写单价得到的本机估算，不代替服务商账单，也不控制 kok 其他 AI 功能的费用。

> [!tip]- 先小额试跑
> 首次使用某个模型时，先用较低的请求上限和较小的档位试一次，确认回答质量后再放宽限制。
