# 发起一个 Agent 任务

[帮助中心](../index.md) / [Agent](index.md)

在智能模式打开 **Agent**。第一次可以发送「统计资料库构成」，看一次本地统计结果。需要总结、写稿或做 PPT 时，请先[配置 AI 服务](../settings/ai-service.md)。

## 空白页与建议

打开 Agent 后，页面中间是输入区，标题为“有什么想法？”，下方有三条建议：**整理思路**、**制定计划**、**制作演示**。选择一条会把提示填入输入框，可以继续修改。添加资料后，建议会跟随资料类型变化，例如单份文档、PDF、视频、照片或多份文件各有不同的建议。

## 添加资料与确定范围

1. 选择 **添加资料**，打开 **添加资料到 Agent** 窗口。
2. 勾选资料库里的文件，或选择 **导入文件** 直接导入本机文件；导入后新资料会自动选中。
3. 最多选择 24 份资料，搜索框可按名称查找。
4. 选择 **添加** 回到任务。

发送前检查范围按钮。你可以指定所选资料、整个资料库或某个文件夹。在创作项目中，默认使用该项目的资料和近期成果。明确选择文件时，以所选为准。要更换范围，打开 **高级设置 → 资料范围**。

> [!tip]- 资料越少越聚焦
> 先选资料再提要求，回答更容易对上你的资料。需要参考整个资料库时，先移除已选资料，再把 **高级设置 → 资料范围** 切换为 **整个资料库**。

## 选择技能与任务方式

展开 **高级设置**：

- **技能**：默认 **自动选择技能**；也可以选择 **不使用技能**，或者指定 **整理资料**、**对比资料**、**读书笔记**、**制作演示** 以及导入的指令技能。
- **任务方式**：**协作修改** 允许提出修改；**仅讨论** 只读取和讨论。
- **用量**：选择省用量、均衡、更多上下文、长任务或超长任务；打开 **用量设置** 可以修改请求上限、单价和费用上限。

## 输入要求并发送

要求写清目标、对象和期望结果，例如：

- “只根据选中的三份文档，对比观点，并列出需要回看原文的地方。”
- “给这些阅读资料建议分类和标签，先展示方案。”
- “把这些资料中的要点整理成 Markdown 笔记。”

选择 **发送** 或按 `Enter` 发送，`Shift+Enter` 换行。任务运行时可选择 **补充要求**（下一轮生效）、**稍后执行**（最多排 5 项待办）或 **停止**。

## 停止、草稿与重新开始

**停止** 后可查看待办和还未发送的要求。输入草稿随会话保存。用 **新建会话** 开始新的对话，或从 **会话** 找回旧对话。在项目里新建会话会保留项目范围，点项目横幅上的关闭按钮可退出。[找回结果与继续任务](results-history.md)
