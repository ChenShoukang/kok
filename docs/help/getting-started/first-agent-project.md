# 用资料做一份报告和 PPT

[帮助中心](../index.md) / 入门

这个练习会把几份资料做成一份可编辑的报告和一份 PPT。你可以用自己的文件，也可以用随包附带的示例练习。

## 准备资料和 AI 服务

1. [导入示例资料](import.md)，或导入同一主题的两三份文档。练习时可以用「给日常一点留白」「整理生活的小清单」「欢迎来到 kok」。
2. 切换到 **智能模式**。打开 **设置 → 功能 → AI 服务 → 配置 API**，填写你的服务地址和模型，按服务要求填写密钥。使用远程服务时，所选资料的相关内容会发送给该服务，测试连接和实际任务可能计费。[配置 AI 服务](../settings/ai-service.md)
3. 打开 **我的作品 → 新建创作项目**。名称可填「本周整理计划」，目标填「完成一页计划和一份可编辑演示」，要求填「只使用所选资料，缺失信息标为待确认」。勾选前面导入的文档，点 **保存**。

## 根据资料写报告

1. 在项目卡片上点 **继续创作**。确认 Agent 输入框上方显示项目名称。需要缩小本次范围时，点 **添加资料** 选择要用的几份。
2. 输入下面的要求并发送。确认任务方式是 **协作修改**，这样 Agent 可以提出创建文件的方案。

   > 用这个项目的资料写一份 Markdown 报告，标题为「本周整理计划」。分成目标、三项行动、待确认事项三节。写明依据来自哪份资料，先给我看准备保存的正文。

3. 展开来源或读取步骤，检查引用能否回到对应文件。核对拟保存的正文，再点 **执行**。想先调整方向，可以 **跳过**，补充要求后再发送。
4. 从 **成果** 打开报告，手动改一段。需要让 Agent 改时，先保存，再选中文字，点 **让 Agent 改这段**，补充要求后发送并审查替换结果。

## 转为演示并继续编辑

1. 在同一项目的 Agent 会话中发送「把刚才保存的《本周整理计划》转为 8 页 PPT，含封面，长说明放在备注。先预览再保存。」
2. 翻看方案，确认每页重点和来源。点 **执行**，然后从 **成果** 打开已保存的演示。
3. 切到 **编辑**，双击文字修改，拖动左侧缩略图调整顺序。只想改一页时，选中该页并点 **让 Agent 改这页**。见[制作与编辑演示文稿](../works/presentations.md)。
4. 重开 kok 后，从 **我的作品 → 创作项目 → 打开项目** 找到报告和 PPT。也可以点 **继续创作**，用新会话继续同一项目。

## 导出和核对

- 报告在编辑器中选 **DOCX → 另存副本**。回到文档的 **版本** 可以对比或恢复可用的历史稿。
- 演示在编辑器里点 **导出 PPTX**。导出后打开副本，核对报告中的重要信息和每页演讲备注。
- 如果 Agent 显示 **回答未完成**，点 **分段继续**，先处理报告的一节或 PPT 的几页。按钮会把草稿放回输入框，待你发送。[找回结果与继续任务](../agent/results-history.md)
