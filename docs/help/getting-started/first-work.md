# 读一份资料，写下第一篇笔记

[帮助中心](../index.md) / 入门

这个练习从资料库读一份示例，再在「我的作品」保存自己的笔记。纯净模式和智能模式都可以完成。

## 用示例试一次

没有托管作品时，可从空白的 **Agent** 首页或 **我的作品** 点 **用示例试一次**。读一行示例，写下自己的下一步，点 **保存并编辑**。这会创建一份普通 Markdown 笔记，可以直接改，关闭后从 **我的作品 → 继续创作** 找回。练习在本机完成，无需配置模型。也可以按下面的步骤手动体验。

## 添加并打开示例

1. 打开 **资料库**。空库时点 **体验示例资料**。已有文件时，可以在 **设置 → 资料库 → 体验示例 → 添加示例** 导入示例。
2. 搜索「给日常一点留白」，打开这份 Markdown 文档。也可以导入自己的 TXT 或 Markdown 文件。见[导入第一份资料](import.md)。
3. 点心形按钮收藏，关闭文档后从 **资料库 → 收藏** 再打开一次。

收藏和导入都保留原文件的位置。以后也能从 **最近打开** 找回刚读过的资料。

## 新建阅读笔记

1. 打开 **我的作品 → 新建作品**，选择 **Markdown**。
2. 选择 **阅读笔记** 模板，把名称改成「我的第一篇阅读笔记」，点 **创建并编辑**。
3. 在正文里写一句摘录和一句自己的想法。例如摘录「一段音乐，一本书，一张留下来的照片」，再写下你想整理的一个文件夹。
4. 等底部显示 **已保存**，关闭编辑器。在 **我的作品 → 继续创作** 打开笔记，检查两句话仍在。

想把笔记发给别人，可以在编辑器里选择格式，再点 **另存副本**。详见[新建与编辑文档](../works/create-documents.md)。
