# 导入第一份资料

kok 的资料库管理的是**本地文件**：可以导入单个文件、整个文件夹，也可以直接把文件拖进窗口。
导入不会移动或修改原文件，只在 kok 中建立索引和记录。

## 三种导入方式

| 方式 | 适合 |
| --- | --- |
| 顶栏 **导入文件** | 导入一个或多个文件 |
| **导入文件** 旁的箭头 → **导入文件夹** | 一次导入整个文件夹 |
| 拖放 | 把文件或文件夹直接拖进窗口 |

## 导入示例资料

如果想先熟悉界面，可以不导入自己的文件：

- 资料库为空时，选择 **体验示例资料**；
- 或在 **设置 → 资料库 → 体验示例** 中选择 **添加示例**。

示例包含视频、照片、音乐、文档和电子书，都是项目内置的原创素材。

## 导入规则

- kok 识别支持的文件类型，跳过已经收录的相同路径。重复导入不会产生重复记录。
- 无法识别或不支持的文件会被跳过，并在导入结果中提示。
- 导入不移动原文件；**移除记录也不会删除原文件**。
- 可以把文件拖进某个分类完成归类，或稍后在文件菜单中编辑分类与标签。

> [!tip]- 扫描文件夹
> 在智能模式下，可以配置并扫描指定文件夹来发现新增文件。具体入口见[智能整理](../library/organize.md)。

## 导入之后

- 按类型浏览：资料库的“全部 / 视频 / 照片 / 音乐 / 文档 / 读书”筛选。
- 打开一份资料，接着上次位置播放或阅读。
- 给常看的内容收藏，或在文件菜单中新建分类。
- 需要时保存摘录，或把资料交给 Agent 处理。

> [!warning]+ 导入不等于备份
> 资料库索引可以备份，但备份不包含原文件。请继续用你的方式备份原始视频、照片和文档。
