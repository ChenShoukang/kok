# 安装 kok

kok 是 Windows 桌面应用，解压已发布的 ZIP 即可运行，不需要安装 Node.js 或 .NET SDK。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，x64 |
| 运行库 | .NET Framework 4.8（Windows 10/11 通常已自带） |
| 浏览器内核 | [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) |
| 可选组件 | FFmpeg / FFprobe（音视频导出）、本地语音识别引擎、系统 OCR（扫描件文字） |

> [!info]+ 首次运行可能安装 WebView2
> 如果系统尚未安装 WebView2 Runtime，kok 依赖的界面无法启动。按提示安装官方运行时后重新打开即可。

## 下载并运行

1. 打开项目的 Releases 页面，下载最新的 `kok-<版本>-win-x64.zip` 和对应的 `.sha256` 校验文件。
2. 校验下载的 ZIP（可选）：将文件哈希与 `.sha256` 内容比较。
3. 把完整 ZIP 解压到一个**可写目录**（例如 `D:\Apps\kok`）。不要只把 `kok.exe` 单独拖出来，
   旁边的运行库和 `ui` 文件夹必须保留。
4. 双击 `kok.exe` 启动。

## 首次启动

- 首次打开时会要求选择**纯净模式**或**智能模式**，可以稍后再改；两种模式的区别见
  [选择使用模式](modes.md)。
- 资料库为空时，可以导入自己的文件，或选择**体验示例资料**先熟悉界面。
- 资料与设置保存在程序目录下的 `data/` 文件夹，**设置 → 资料库 → 关于 kok** 会显示实际路径。
  整个程序目录可以整体移动到其他位置，`data/` 会跟着走。

> [!tip]- 把资料库放在别处
> 高级用法：启动参数 `--data-dir <目录>` 可以让 kok 使用指定目录作为资料库，便于便携或隔离测试。
> 同一个资料库同时只能被一个 kok 窗口打开。

## 更新

kok **没有自动更新**。更新时：

1. 备份 `data/` 文件夹（或至少保留不动）。
2. 下载新版本的 ZIP 并解压到新的程序目录，或覆盖旧程序文件。
3. 保留原来的 `data/` 与可选的组件目录，再启动新版本。

> [!warning]+ 不要在更新时删除 data/
> `data/` 里是资料索引、笔记、进度和设置，不是程序缓存。删除它会丢失应用内记录（原文件不受影响）。
