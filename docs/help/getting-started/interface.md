# 认识界面

kok 的界面由一个窄侧栏和主内容区组成。主内容区显示当前区域；播放、阅读和编辑在独立的查看器或
编辑器中进行，不打断资料库的浏览位置。

## 侧栏

侧栏集中所有一级入口，从上到下是：

- **Agent**：对话和任务（仅智能模式显示）。
- **我的作品**：新建、继续创作与项目管理。
- **资料库**：观看、收听、阅读和管理内容。
- **私密文件夹**（锁形图标）：需要密码的受保护区域，两种模式都可使用。
- **设置**（底部齿轮）：外观、功能、资料库与模块配置。

选择左上角的 kok 标志可以回到默认首页：智能模式回到 Agent，纯净模式回到资料库。

## 顶栏

资料库和我的作品页面顶部有全局操作：

| 操作 | 作用 |
| --- | --- |
| 搜索框 | 搜索资料库，`Ctrl+K` 可聚焦并打开命令面板 |
| **新建** | 新建文档或演示文稿（`Ctrl+N`，随启用的模块变化） |
| **导入文件** | 导入文件或文件夹；旁边的箭头提供更多导入方式 |

Agent 页面会收起这些资料库操作，把空间留给任务输入区。

## 查看器

打开视频、音乐、文档、照片或电子书时，会进入查看器。查看器顶部提供收藏、笔记、使用系统应用打开和
关闭；不同资料类型还有各自的工具，例如视频的字幕与倍速、文档的目录与书签、照片的缩放与编辑。

`F8` 在工作布局与沉浸布局之间切换，kok 会按资料类型记住你的选择。笔记和资料 AI 面板在查看器旁边打开。

## 音乐播放条

播放音乐时，窗口底部会出现播放条：封面、曲名、播放/暂停、上一首/下一首、随机与循环、进度、音量和队列。
播放条会常驻，允许你一边听音乐一边浏览资料或使用 Agent。

## 三个区域的职责

| 区域 | 打开后默认做什么 |
| --- | --- |
| Agent | 描述目标、添加资料、查看任务进程与成果 |
| 我的作品 | 继续未完成的草稿，或新建文档与演示文稿 |
| 资料库 | 继续观看/阅读，按类型浏览，管理收藏和分类 |

> [!tip]- 看不到某个入口？
> 入口会随使用模式、模块开关和个人设置变化。例如纯净模式不显示 Agent，停用下载模块后不再显示视频下载。
> 可以在[模块管理](../settings/modules.md)中恢复。
