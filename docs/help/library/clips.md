# 保存摘录

这页介绍怎样把文字、音视频时间段或照片区域保存成摘录，以及之后怎样找回和继续使用。想留住一段话、一个画面或一段旋律时看这里。

## 创建摘录

打开一份资料，在查看器右侧的详情区选择 **创建摘录**：

- **文字**：先在正文或 PDF 中选中一段文字，摘录会带入所选内容，也可以在表单里继续补充。
- **音视频**：填写开始与结束秒数，摘录只记录时间段。
- **照片**：先拖动框选区域，保存的是画面中的一块位置。

给摘录起一个标题，在 **内容与想法** 里写下原文或你的想法，然后选择 **保存摘录**。

## 从摘录回到来源

摘录保存在资料库的应用内记录里。打开 **摘录** 页（**我的作品 → 工具 → 素材摘录**），卡片会显示标题、内容、来源文件名和时间点。选择摘录会打开原资料并回到原处：文字会重新选中，音视频跳到起始时间并在结束处暂停，照片会短暂框出保存区域。

选择卡片右侧的按钮可以 **编辑** 摘录或 **加入空间**；摘录也可以拖到空间、笔记、演示文稿或 Agent 输入区，作为引用或新的资料范围。拖进演示文稿会新建一页。

> [!warning]+ 注意
> 摘录保存的是位置与文字，不是原文件的副本。来源文件被移动、删除或移出资料库后，摘录无法打开原处；需要长期保留的内容请另外备份原文件。

## 摘录的边界

摘录不会生成新的音视频文件，也不会复制照片，它依赖原文件和 kok 的记录。私密文件夹中的内容不进入普通资料库的摘录与空间。导出资料库时摘录随应用内记录一起导出，但原始文件仍需另行保管。
