# 继续、收藏、最近与分类

这页说明资料库首页上的几种找回方式：继续观看与阅读、收藏、最近打开，以及分类的组织规则。

## 继续观看与阅读

**继续观看与阅读** 会列出未完成的视频、音乐、书籍和文档，最多 6 项，按最近打开排序。只显示已经开始且进度在 1%–99% 之间的内容；看完到接近 100% 后会自动从这个列表消失，从 **最近打开** 仍然能找到。

选择一项即可回到对应播放器或阅读器，并从上次保存的位置继续。

## 收藏

卡片右上角的心形按钮用于收藏或取消收藏，文件菜单里也有 **加入收藏 / 取消收藏**。首页的 **收藏** 快捷入口会显示收藏数量，进入后只显示已收藏的内容。

收藏是纯标记，不会移动文件，也不会影响播放和阅读进度。

## 最近打开

首页的 **最近打开** 快捷入口按打开时间列出资料，适合找回刚看过但没收藏的内容。最近页默认按最近打开排序，不显示类型筛选标签；没有打开记录时会提示为空。

## 分类

分类是资料库内部的归档方式：

- 在首页选择 **新建分类**，填写名称即可创建；分类标签会显示在首页 **分类** 区域。
- 拖动文件卡片到分类标签即可归入该分类；可以先按住 `Ctrl` 或 `Shift` 选择多张卡片再拖动。
- 在文件菜单中选择 **编辑分类与标签** 可以修改分类和标签，选择 **分类归纳** 可以把单个文件归入已有或新建分类。
- 选择分类标签进入分类页，页面顶部可以返回资料库。

> [!info]+ 说明
> 分类只改变 kok 中的组织关系，不会替你移动磁盘文件。从资料库移除记录也不会删除原文件；私密文件夹里的内容不会出现在普通分类与搜索结果中。

## 它们之间的关系

**继续** 记录进度，**收藏** 是标记，**最近打开** 是使用历史，**分类** 是长期组织方式，四者互不影响。同一个文件可以同时出现在继续列表、收藏页和某个分类中。
