# 资料库概览

资料库是 kok 观看、收听、阅读和管理本地内容的地方。导入文件后，从侧栏进入 **资料库** 就能按类型找到它们。

## 首页结构

资料库首页从上到下依次是：

- **继续观看与阅读**：最多 6 项未完成的内容，显示进度，选择后从上次位置继续。
- **收藏** 与 **最近打开**：两个快捷入口，分别显示收藏数量和最近打开过的资料。
- **分类**：已有分类标签和 **新建分类** 按钮，选择分类进入分类页。
- **类型筛选**：**全部**、**视频**、**照片**、**音乐**、**文档**、**读书**。
- **视图与排序**：网格或列表视图；排序可选最近加入、最近打开、名称和文件大小。
- **资料库工具**：工具栏右侧的更多按钮，集中放置智能整理、视频下载、知识图谱、智能集合、回顾、操作历史、活动与资料检索与备份。

每张卡片都可以直接打开（播放、阅读或预览），右上角的心形按钮用于收藏，更多操作里可以编辑分类与标签、在文件夹中显示或使用系统应用打开。

## 三个常用阅读路径

1. **从资料库首页进入**：用类型筛选或分类缩小范围，再打开具体资料。
2. **从收藏进入**：把常看的内容点成收藏，从首页 **收藏** 快捷入口直达。
3. **从最近打开进入**：按打开时间找回刚看过但没收藏的内容。

## 与我的作品的分工

**资料库** 面向欣赏与整理：观看、收听、阅读、收藏、分类和搜索已有内容。**我的作品** 面向创作：新建文档与演示、继续编辑草稿、进入空间与配方。导出成品会回到资料库，和普通资料一样欣赏；资料也可以成为作品素材，但不会被复制成两份文件。

> [!tip]- 小提示
> 导入文件可以拖到窗口，也可以选择 **导入文件**。私密文件夹是资料库里的密码文件夹，内容不会出现在普通分类和搜索结果中。
