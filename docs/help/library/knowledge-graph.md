# 查看知识图谱

知识图谱把资料、笔记与标签之间的关系画成节点和连线。想看看一组笔记之间已经建立了哪些链接时打开它；它展示已有关系，不会替你推断新的事实关联。

## 打开与查看

在资料库首页工具栏选择 **资料库工具 → 知识图谱** 打开。

- 滚轮缩放，拖动节点或空白处平移；**适应图谱** 让全部节点回到视野。
- 选择节点查看它的关联；双击节点打开对应资料或笔记。
- 右侧列表与图谱同步，也可以直接搜索笔记或标签。
- 顶部显示当前视图的节点与关系数量。

> [!warning]+ 注意
> 图谱只画已经存在的链接和关系，例如笔记里的 `[[双向链接]]`、标签和分类归属。两条资料在图谱里靠近，不代表它们的内容互相印证。

## 范围与筛选

图谱范围可选 **全部资料**、**按分类**、**收藏** 或 **手动选择**；关联范围可选 **一层关联**、**两层关联** 或 **全部笔记**。展开 **筛选与保存范围** 还可以按类型、标签、加入日期筛选，并决定是否显示标签与独立笔记。

节点上限可以选择 100、250 或 500，单个视图最多显示 500 个节点；范围过大时图谱会提示先搜索或筛选。筛选条件可以命名保存，之后从 **已保存范围** 重新套用。

## 数据与边界

图谱的关系来自普通资料的文件名、分类、标签、笔记、批注想法和可读正文，不调用 AI，纯净模式也可以使用。私密文件夹的内容不参与图谱，切换资料库会清空界面中的图谱数据。正文很长时可能只索引一部分，界面会提示覆盖情况。

智能模式下还可以在图谱里使用 **AI 分析**，把选中的关系交给模型总结；分析结果仍需回到原资料核对。
