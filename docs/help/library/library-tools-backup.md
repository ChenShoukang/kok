# 资料库工具、历史与备份

资料库工具栏的 **资料库工具** 把整理、检索、历史和备份入口收在一起。这页说明各入口的用途与导出、撤销和后台任务的范围。

## 资料库工具菜单

在资料库首页工具栏选择更多按钮，打开 **资料库工具**：

| 入口 | 用途 | 需要智能模式 |
| --- | --- | --- |
| 智能整理 | 扫描文件夹并建议分类、标签 | 是 |
| 视频下载 | 下载网页视频与音频 | 是 |
| 知识图谱 | 查看资料与笔记的关系 | 否 |
| 智能集合 | 保存筛选条件 | 否 |
| 回顾 | 按天查看打开记录与摘录 | 否 |
| 操作历史 | 查看并撤销应用内修改 | 否 |
| 活动 | 查看后台任务 | 否 |
| 资料检索与备份 | 正文索引、语义检索、导出与恢复 | 索引与导出不需要 |
| 交给 Agent | 把所选资料交给 Agent 继续处理 | 是 |
| 多文件对比与笔记回顾 | AI 对比与笔记归纳 | 是 |

## 检索、导出与恢复

选择 **资料检索与备份** 打开面板：**更新正文索引** 与 **全部重建** 维护可搜索的正文；**检索资料** 提供文字、混合与语义三种方式；**本机语义检索** 需要本机 Ollama 与 embedding 模型。

在 **导出与恢复** 区域选择 **导出便携资料库**，生成 `.koklib` 便携包，包含笔记、摘录、空间、来源身份和 kok 托管文档，可选包含其他原文件。单个附件最多 2 GB、总附件最多 8 GB、最多 10,000 份资料；便携包不包含 AI 密钥、聊天与任务历史、记忆、私密库、封面缓存和 embedding 索引。**恢复到新资料库** 会先校验格式、ID 与哈希，再创建独立新库，现有资料库继续可用；新库默认纯净模式，缺失原件可以逐项重新关联。详细边界见[检索、采集与可恢复资料库](../../LIBRARY_0.9.0.md)。

## 操作历史与撤销

**操作历史** 列出 Agent、配方、批量操作和你的修改，显示时间、状态和前后值。已执行的操作可以选择 **撤销**；撤销会保留之后的人工修改，遇到冲突时提示并保持现状。在资料库列表中（未打开查看器、也不在输入框内）按 `Ctrl+Z` 可以撤销最近一次已执行的修改。撤销只回退 kok 中的记录与索引，不会删除原文件。

## 活动与后台任务

**活动** 汇总 Agent 任务和下载任务的状态与进度。支持续跑的任务才有 **暂停** / **继续**，其他任务只能 **取消**；已完成的任务可以 **查看结果**，Agent 任务还可以打开 **任务详情**。关闭 kok 后任务停止，重开后保留暂停或取消状态。

## 备份与私密文件夹

普通资料库的备份在 **设置 → 资料库 → 资料库备份 → 导出**：生成 JSON 快照，包含索引、笔记、进度、空间与摘录等记录，不含原始文件。私密文件夹中同样的按钮导出 `.kokvault`，包含加密索引与笔记，仍需原密码读取，也不含原文件。私密备份目前没有一键恢复，手动恢复步骤见[私密说明](../../MODES.md)。

> [!warning]+ 注意
> 两种备份都不含原始文件，JSON 快照是明文。换电脑时请同时复制原文件，优先使用便携资料库流程。
