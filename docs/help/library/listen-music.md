# 收听音乐与音频

这页介绍资料库里的音乐与音频：怎样按专辑和歌手浏览、修正标签，以及使用播放队列和后台播放条。

## 浏览音乐

在资料库的类型筛选中选择 **音乐**，进入音乐与音频页面。顶部可以在 **专辑**、**歌手**、**我的音频**、**全部音频** 四种视图之间切换，右侧可以按曲名、歌手或专辑搜索。

- **专辑**：按专辑分组，选择专辑可以播放整张专辑。
- **歌手**：按歌手分组，未填写歌手的音乐会归在“未填写歌手”。
- **我的音频**：录音、播客、音效等非歌曲音频。
- **全部音频**：全部音乐与音频的平铺列表。

列表右侧提供 **音频信息**、**编辑音频** 与收藏按钮；文件菜单里也有 **音频信息与匹配** 和 **编辑音频**。

## 标签与封面

kok 在本地读取音频的名称、歌手、专辑、曲目、年份、风格、时长和内嵌封面，不改写原文件。缺少标签时会尝试从规范的“歌手 - 曲名”文件名推断，也可以手动修正。

在智能模式下，音频信息里还可以选择 **联网匹配**：只把曲名和歌手发送到 MusicBrainz，展示候选版本，选中并保存后才应用，不上传音频。**AI 整理** 会先预览将发送的文件名与标签，再生成分类与摘要，确认后应用。

> [!info]+ 说明
> 标签能读取不等于音频一定能内置播放。遇到无法解码的音频时，可以使用更多操作中的系统应用打开。

## 播放队列与后台播放

播放音乐后，底部会出现常驻播放条，切换到其他页面也不会中断。播放条提供播放 / 暂停、上一首、下一首、进度、音量、随机与循环，并会记住每首歌的播放位置。

音乐工作区里可以查看 **播放队列**、拖动进度、切换随机或循环，也可以选择 **收起播放器** 回到资料库。播放和暂停也可以按 `空格`；需要独立查看时选择右上角的独立窗口。

## 录音、播客与音效

在 **音频信息** 的 **类型** 中把音频设为歌曲、录音、播客 / 有声内容、音效或其他音频，即可在 **我的音频** 中按类别归纳。类型只改变 kok 中的归类，不移动也不改写音频文件。
