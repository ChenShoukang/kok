# 阅读文档与电子书

这页介绍在资料库中阅读电子书、文档和 PDF，以及目录、全文搜索、书签与阅读排版设置。

## 打开与目录

在资料库选择书籍或文档即可打开阅读器。EPUB 优先读取书内目录，兼容 NCX、嵌套目录和重复标题；TXT 与 Markdown 会识别章节标题；Word 文档识别标题层级。没有正式目录时会回退到正文分节。

阅读进度、章节和书签会自动保存，关闭后再打开会回到上次位置。左侧目录可以显示或收起；在阅读工具中打开 **我的书签** 可以添加、跳转或删除书签，并支持导出笔记与书签。

## 阅读排版

阅读器的排版设置包括：

- **布局**：连续滚动、单页或双页；电子书默认左右分页，文档默认连续滚动。
- **字体与字号**：内置清晰宋体、清晰黑体、霞鹜文楷、得意黑等，也可以导入 TTF / OTF 字体；字号可在 14–48 px 调整。
- **行距、字距、段落留白与正文宽度**：按阅读习惯微调，设置保存在本机。
- **配色**：跟随界面、柔和纸色、护眼绿或夜间阅读。

## 搜索、标记与笔记

- **全文搜索**：在阅读工具中搜索整本文档或书籍，最多显示 200 个匹配；选择结果会跳转，也可以返回搜索前的位置。
- **标记**：选中文字后可以加下划线、荧光标记或写下想法，选区支持微调；标记与想法会列在笔记面板中。
- **导出**：带标记的阅读副本可以导出为 HTML，包含划线、想法与随手记；书签面板可以另行导出笔记与书签。
- 电子书可以用 `←` / `→` 切换章节，按 `Esc` 关闭查看器。

## 阅读 PDF

PDF 支持本地页面预览、页码跳转和缩放（70%–150% 或适合宽度），可以切换 **夜间文档** 与 **易读文字**。易读文字会从有文字层的 PDF 提取分页正文，支持独立排版、选字、标记和书签，也可以切回原版；它不包含 OCR，也不重建原页面布局。

PDF 上可以划线、荧光、补充批注，并在页面位置插入文字。所有标记保存在 kok 中，不直接写回原 PDF，可以导出批注摘要带走。若 PDF 自带大纲，左侧目录会显示章节；扫描版 PDF 没有文字层，需要先做文字识别。

> [!warning]+ 注意
> PDF 批注不会写进原文件，换用其他阅读器看不到；需要保留批注时请导出批注摘要。扫描件也需要 OCR 后才能搜索文字。
