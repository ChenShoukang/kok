# 回顾使用记录

回顾按天汇总你打开过的资料与进度，并列出保存的摘录。想看看这周读了什么、看到哪里，或者把一段时间的记录存成笔记时用它。

## 打开回顾

在资料库首页工具栏选择 **资料库工具 → 回顾** 打开。

页面按日期分段，每段列出当天打开过的资料，显示类型、名称和进度百分比。选择条目会打开原资料，并从保存的阅读或播放位置继续。页面下方会按保存时间列出摘录，选择摘录可以回到来源。

还没有打开记录时，页面会提示先打开一份资料。

## 保存回顾笔记

选择页面右上角的 **保存回顾笔记**，kok 会生成一份 Markdown 笔记，标题带有当天日期，正文包含这段时间的打开记录与进度。生成后可以在 **我的作品** 或资料库中找到并继续编辑，也可以照常导出。

> [!info]+ 说明
> 回顾只使用本机记录，不调用 AI，也不会上传内容。记录来自 kok 中的打开与进度更新；只放在磁盘上、没有导入资料库的文件不会出现在回顾里。

## 回顾能做什么、不能做什么

回顾适合回看自己的使用轨迹和待续内容，它不是阅读统计报表，也不会自动分析内容。需要基于笔记与划线做归纳时，请使用智能模式下的 AI 工具。
