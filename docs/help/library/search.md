# 搜索与检索

这页介绍怎样在 kok 中搜索资料、用 `Ctrl+K` 打开命令与资料，以及建立索引和启用语义检索的前提。

## 顶栏搜索

在顶栏输入关键词，列表会立即过滤，页面标题变成 **搜索结果**。搜索会匹配文件名、格式、笔记、标签和摘要，也会查询已建立索引的正文、PDF 文字层和字幕内容。

按 `Ctrl+K` 打开 **命令与资料**：可以直接搜索并执行命令，也会匹配文件名和索引内容；用方向键选择，按 `Enter` 执行。在列表页按 `Ctrl+F` 也会把光标移到顶栏搜索框。

## 检索方式

顶栏搜索框旁有检索方式下拉，提供三种模式：

- **文字**：默认方式，使用全文索引做字面匹配。
- **混合**：综合文字匹配与语义结果，按相关度合并排序。
- **语义**：按含义查找相近内容。

混合与语义只在智能模式下可用，纯净模式会回到文字匹配。语义检索需要先在 **资料检索与备份** 中启用本机 embedding 服务（填写 Ollama 地址和模型名称）并建立语义索引。模型未启用、索引未建立或不可用时，kok 会回退到文字匹配并给出提示。

## 建立正文索引

第一次使用全文搜索前，建议先建立索引：打开资料库首页的 **资料库工具**，选择 **资料检索与备份**，然后：

- 选择 **更新正文索引** 做增量更新，或 **全部重建**。
- 展开 **查看索引覆盖与失败原因**，确认哪些资料未完全索引。
- 在 **本机语义检索** 中填写 Ollama 地址与模型，启用后建立语义索引。

导入或编辑资料后，索引会安排增量更新。索引覆盖标题、笔记、标签、摘录、支持格式的正文、PDF 文字层、PPTX 文字与备注，以及第一条可用字幕，并保留页码、章节和字幕时间。

## 能定位到什么

搜索结果可以定位到具体位置：文档的章节、PDF 的页码、视频字幕的时间点或摘录的锚点。选择结果后会重新核对来源版本，再打开原处。

> [!warning]+ 注意
> 扫描版 PDF 没有文字层时不会凭空产生可搜索文字。可以先在 **资料检索与备份** 中使用 **本机文字识别**（Windows OCR），把图片或 PDF 页面识别进索引；识别文字不会写回原文件。语义模式给出的只是相近候选，不等于对内容的事实回答。
