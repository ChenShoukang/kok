# 使用智能集合

智能集合把一组筛选条件保存下来，结果随资料库变化自动更新。经常按“最近导入、还没看过的 PDF”这类条件找资料时，可以先建一个集合。

## 新建集合

在资料库首页工具栏选择 **资料库工具 → 智能集合**，再选择 **新建集合**。表单包括：

- **名称**：给集合起一个容易识别的名字。
- **关键词**：在已建立索引的文件名、正文、笔记等中匹配，留空表示不限。
- **类型**：全部、视频、照片、音乐、文档或读书。
- **标签**：按标签匹配。
- **最近几天**：只看最近若干天加入的资料，填 0 表示不限时间。
- **尚未阅读或播放**：只保留进度为 0 的资料。

选择 **保存** 后，集合会出现在列表中。

## 查看、编辑与结果更新

选择集合名称，下方会列出当前匹配的资料，和资料库卡片一样可以打开、收藏或加入空间。集合行右侧的铅笔按钮可以编辑条件，编辑弹窗里也能删除这个集合。

匹配在本地完成，不需要配置 AI 服务，也不会向外部发送内容。资料库导入新资料、更新进度或修改标签后，下次打开集合会按当前条件重新匹配。资料库较大时，关键词匹配依赖 **资料检索与备份** 中维护的正文索引。

> [!tip]- 小提示
> 把 **最近几天** 与 **尚未阅读或播放** 组合，就是一份“最近导入、还没看”的待办清单；把 **标签** 与 **类型** 组合，可以固定追踪某一类主题资料。

## 与普通搜索的区别

顶栏搜索是一次性的关键词查询；智能集合保存的是可以反复打开的条件。集合只筛选已收录的资料，不移动磁盘文件、不复制内容，也不会自动改变资料分类。
