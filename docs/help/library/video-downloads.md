# 下载网络视频

视频下载把网页里的视频或音频保存到本机并加入资料库。入口只在智能模式出现；解析由 kok 内置完成，不消耗 AI 密钥。

## 粘贴链接并解析

在资料库首页工具栏选择 **资料库工具 → 视频下载**。在输入框粘贴网页或音视频链接，每行一个，最多 20 个，然后选择 **解析链接**。

解析后可以：

- 有多个资源时在 **选择资源** 中切换。
- 选择 **下载格式**：最佳可用画质、最高 1080p、720p、480p 或 **仅音频**。
- 勾选 **保存网页已有字幕**。
- 用 **更改位置** 指定保存文件夹，再选择 **开始下载**。

Bilibili 与抖音的单个链接还会出现 **网页辅助解析**，用浏览器打开页面协助解析。

## 队列、续传与入库

**下载队列** 显示每个任务的状态：等待下载、正在下载、正在整理媒体、已完成、已暂停、已取消或下载失败。进行中的任务可以 **暂停** 或 **取消**；暂停、失败或取消的任务可以选择 **继续或重试**。

直链支持断点续传；分段任务在暂停后会重新开始。下载完成后媒体会自动加入资料库；如果自动入库失败，任务上会出现 **加入资料库** 按钮，也可以选择 **在文件夹中显示**。**清理已结束的任务** 只清理队列记录，不删除已下载的媒体文件。下载记录最多保留 100 条，满了先清理。

## 登录与媒体组件

在 **站点与登录** 中可以分别处理哔哩哔哩、YouTube 和抖音：**打开登录** 使用你自己的账号，或 **导入 cookies.txt**；已经保存的信息可以 **清除**。已保存的登录信息只代表本机保存过，不代表站点授权一直有效。

需要 M3U8 / DASH 点播或把分离的音视频合并时，要在 **媒体组件** 中安装 FFmpeg / FFprobe，或选择已有的安装。组件是可选的外部工具。

> [!warning]+ 注意
> 画质与可用性取决于来源。网站改版可能让解析失效，部分需要登录、加密或付费的内容不保证可下载；请只保存你有权保存的内容。
