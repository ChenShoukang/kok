# 浏览与编辑照片

这页介绍在资料库中查看照片、做简单调整和标注，并把结果另存为新照片。

## 浏览照片

选择照片卡片即可在查看器中打开：

- 使用左右按钮或 `←` / `→` 切换上一张、下一张。
- 滚轮缩放，放大后可以拖动查看；A− / A+ 调整缩放，旋转按钮可以转动画面。
- 选择 **幻灯片** 会每 4 秒自动切换下一张；双击内容空白处可以切换适应窗口。

JPG、PNG、GIF、WebP、BMP、AVIF 可以内置预览；TIF、TIFF、HEIC、HEIF 需要系统图片应用打开。动图编辑时只按当前静态画面处理。

## 基础调整

选择照片工具栏的 **编辑** 进入照片编辑器，可以：

- 选择 **原图**、**柔和**、**鲜明**、**黑白**、**复古** 等预设。
- 调整亮度、对比度、饱和度、色温、黑白程度、复古程度和暗角。
- 按原始比例、1:1、4:3、3:2、16:9、3:4、9:16 裁剪，调整裁剪位置，或旋转、水平翻转、垂直翻转。
- 使用自由裁剪拖出选区，再拖动控制点微调。
- 随时选择 **对比原图** 查看差异，或 **重置调整** 恢复初始状态。

## 文字与标注

编辑器提供文字、画笔、矩形、箭头和遮挡工具，可调整颜色与大小。标注以图层方式管理，可以选中、上移或删除；所有操作都支持撤销与重做。文字与绘制内容可以拖动调整位置。

> [!tip]- 小提示
> 调整过程中可以随时返回照片预览；想下次继续修改时，先选择 **保存调整** 记录草稿，再次打开这张照片会自动恢复。

## 保存与限制

调整完成后选择 **另存为新照片**，会生成新的图片副本（PNG / JPEG）并加入 **资料库**，原照片保持不变。保存前可以选择导出尺寸：2048 px、4096 px 或原始尺寸，默认按长边 4096 px 输出。

照片编辑只做基础调整和标注，不包含抠图、人像修饰或批量处理。编辑输出为静态图片，GIF 动图不会保留动画。
