# 观看视频

这页介绍资料库里的视频播放功能：续播、倍速、全屏、字幕，以及封面和视频属性。第一次打开视频或想调整播放设置时可以看这里。

## 播放与续播

在资料库选择视频卡片即可打开播放器。播放进度按秒保存：关闭后再打开，会从上次的位置继续。

底部控制条提供播放 / 暂停、后退与前进（默认 10 秒，可在 **播放偏好** 调整）、进度拖动和音量。默认按 `空格` 播放或暂停，也可以在播放偏好中改为 `K` 或 `P`。内核支持时还可以使用画中画；无法内置解码的格式会提示使用系统应用打开，原文件保持不变。

## 倍速、静音加速与全屏

- **倍速**：在 **播放设置** 中选择 0.5× 到 3×。
- **静音自动加速**：打开后，检测到无声片段时会临时加快播放，画面上会显示当前倍速；检测不到时仍可手动调整倍速。
- **全屏**：选择 **全屏**、按 `F` 或 `F11`，或按偏好双击画面进入；全屏不显示窗口边框，按 `Esc` 退出。
- **自适应窗口**：在查看器右上选择自适应，画面会按比例适配窗口，横屏和竖屏素材都不会被裁掉。

全屏时控制条会在闲置后淡出，移动鼠标或按键盘即可唤回。

## 字幕

kok 会自动寻找与视频同名（含语言后缀）的外挂字幕并加载。打开 **播放设置** 后：

- 用 **字幕** 下拉切换字幕轨或关闭字幕。
- 选择 **载入字幕** 手动指定外挂字幕文件。
- 支持 SRT、VTT、ASS、SSA、SUB、SBV、LRC、TTML、DFXP、SMI；ASS / SSA 只显示文字，不还原特效。
- 内嵌字幕和位图字幕不能读取，需要另配外挂文字字幕。
- 智能模式下可以把已有字幕整理成可跳转的 **字幕目录**，它只分析字幕，不识别画面；没有字幕时请先载入或生成字幕。

## 封面、属性与独立窗口

视频卡片会自动截取画面作为封面。右键视频画面可以打开 **视频属性**，查看文件名、位置、类型、大小、时长、分辨率和修改时间；编码与音轨信息暂不解析。

选择查看器右上角的 **在独立窗口打开**，可以把视频拆到可移动的独立预览窗口；窗口顶部标签可以切换或聚焦已打开的窗口，双击内容空白处可以让窗口退到主窗口后面。

> [!info]+ 说明
> 视频能否播放取决于容器、内部编码、WebView2 和系统解码能力。推荐 H.264 / AAC 的 MP4；解码失败时请使用系统播放器，kok 不会转码。
