# 能力边界与未实现

kok 把很多能力放在同一个应用里，但仍有一些事它不做，或者这一版还没做完。这页把边界写清楚，遇到“怎么没有这个按钮”时可以先来这里确认。

## 播放与格式

- 播放依赖 WebView2 和系统已安装的编码。kok 不内置独立解码器，也不提供转码。
- 后缀能收录不代表能内置播放：AVI、WMV、TS、HEIC、MOBI 等建议使用系统应用打开。
- 不处理 DRM，不解密受保护的电子书和媒体，也不保证所有登录、加密或付费内容都能下载。
- 扫描 PDF 可以借助 Windows OCR 检索，但不会把识别文字写入 PDF 文字层。
- 画中画能否使用取决于 WebView2 内核是否支持。

## 编辑与保真度

- DOCX 的编辑与导出只重建简洁正文，不保留原始排版、图片、表格布局或宏；EPUB 同样不还原图片与复杂排版。
- PPTX 提供基础文字与页面编辑；复杂母版、图表、动画和嵌入对象不能完整还原。
- PDF 页面整理中，编辑过的画布页面按图像导出；批注保存在 kok 中，不写回原 PDF。
- 照片动图按静态画面处理，编辑输出长边最多 4096 px。
- 音视频只处理已有媒体；导出、合并和分轨处理通常需要另装 FFmpeg / FFprobe。

## AI 与费用

- AI 需要兼容 OpenAI 接口的服务，服务商和模型由你选择；没有配置时不能使用 Agent、翻译等能力。
- 发送给服务商的是你执行 AI 功能时选定的内容，长文、字幕和画面可能被节选。
- 费用由服务商计算；kok 里填写的单价、请求上限和额度用于估算与控制，不代替服务商账单。
- 模型可能出错，回答需要对照来源核对；聊天接口不等于语音识别，理解画面需要支持图片输入的模型。

## 本地优先与隐私

- 导入只记录文件路径，不移动、不复制、不加密原文件；移除记录不删除原文件。
- 私密文件夹保护应用内的索引、笔记与封面，不保护原文件，也不会追溯加密此前导出的备份。
- 没有账号体系，也没有内置云同步、手机版或自动更新；当前只支持 Windows 10 / 11 x64。
- 联网搜索、网页采集、视频下载会按你的操作访问网络；MCP 外部工具可以访问当前账户的文件和网络，且不能自动撤销。
- 当前是未签名的 Preview 预览版，功能和格式可能继续调整，请保留自己的备份。

## 本版尚未实现

- 小说作品级大纲、人物设定、章节管理与连续性检查；本版只提供文本写作和基础导出。
- 从零生成可播放的音乐或视频；本版只支持剪辑、拼接已有媒体。
- 作品级原生状态、版本库与导出记录；“我的作品”暂时按已有资料和编辑草稿推导，作品还没有原生版本历史，请用操作历史、草稿和导出副本保管重要内容，未来会补齐。

> [!warning]+ 不要把规划当成现有功能
> 上面“尚未实现”的三类能力在 v0.10.1 中没有入口，也没有可绕过的替代路径。看到相关教程或截图时，请以本版实际界面为准。

> [!info]+ 边界会随版本更新
> 格式、编码和组件支持会随 WebView2、系统和 kok 版本变化；具体验证范围见[格式兼容性](../../FORMATS.md)与[本版验证记录](../../VALIDATION_0.10.1.md)。
