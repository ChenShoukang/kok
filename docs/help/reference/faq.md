# 常见问题

以下说明适用于 v0.11.2 Preview。查看特定格式或功能的限制，见[能力边界与未实现](boundaries.md)。

## 使用与数据

### 使用 kok 需要联网吗？

不需要。播放、阅读、编辑、整理和记录都在本机完成；只有使用 AI 功能、联网搜索、视频下载或联网匹配音乐信息时才会联网。

### kok 会把我的文件上传吗？

不会自动上传。只有你执行 AI 功能时，选定的内容才会发送给你在设置中配置的服务；纯净模式和私密文件夹会阻止 AI 请求。

### 我的数据保存在哪里？

资料索引、笔记、进度和设置保存在程序目录下的 `data/` 文件夹。实际路径可以在 **设置 → 资料库 → 关于 kok** 查看；原文件仍留在它们原来的位置。

### 换电脑时怎么迁移？

普通资料可通过 **资料库工具 → 资料检索与备份** 导出 `.koklib`，在新电脑恢复到新资料库。它带上托管文档，其他原件可选带上。模型密钥需重新配置。Agent 历史和私密库有不同的备份范围。[数据、备份与更新](../settings/data-backup.md)

### 升级 kok 会丢数据吗？

先退出应用并备份资料库。使用新程序时保留原 `data/`，或继续使用之前的 `--data-dir` 路径。[更新方式](versions.md#更新方式)

## AI 与费用

### Agent 为什么不可用？

Agent 需要智能模式并配置 AI 服务；纯净模式和私密文件夹不发送 AI 请求，对应模块停用时入口也会消失。没有配置模型时，仍可以先试统计、列表这类由本地规则直接回答的任务。

### AI 费用怎么算？

费用由 AI 服务商按实际用量计算。kok 里填写的单价、请求上限和额度用于估算与控制，不是服务商账单，也不能保证不超支。

### Agent 显示「回答未完成」怎么办？

点 **分段继续**，把任务缩小到一段文字或几页 PPT，再发送。输入框会保留原要求和本次使用的资料。[找回结果与继续任务](../agent/results-history.md#回答未完成)

### 忘记私密文件夹密码了怎么办？

密码无法找回：kok 不保存明文密码，也没有后门。原文件不受影响，但私密库里的索引和笔记无法再打开；请保留 `.kokvault` 备份并牢记密码。

## 能力与限制

### 为什么有些视频不能播放？

后缀能收录不等于能解码。kok 使用 WebView2 和系统编码，AVI、WMV、TS 等格式建议使用系统播放器；MKV 也可能因为编码或轨道不支持而无法完整播放。遇到无法播放的文件，可以在文件菜单里选择**使用系统应用打开**。

### 为什么 PPTX 打开后排版不一样？

kok 只重建基础文字和页面元素，复杂母版、图表、动画和嵌入对象不能完整还原；导出的 PPTX 也遵循同样的范围。

### “我的作品”里为什么没有显示某个文件？

只导入、还未编辑的文件可以在资料库找到。「继续创作」列出近期托管作品和本地编辑草稿。已登记到项目的成果可从「打开项目」找回。[继续创作项目](../works/continue-editing.md)

### 怎么找回文档旧稿？

打开 kok 创建的 Markdown、TXT 或 DOCX，点 **版本**。选择历史稿可以对比或恢复，也可以为历史版本命名。PPT 的阶段稿可用 **导出 PPTX** 保存副本。[编辑、对比与恢复文档](../works/create-documents.md)

### 小说、音乐和视频能从零生成吗？

还不能。小说可以用文本编辑器写作，但作品级章节与设定管理尚未提供；可播放的音乐和视频需要生成引擎，本版只支持剪辑、拼接已有媒体。这些能力会分阶段接入。

### 纯净模式下哪些功能不能用？

Agent、翻译、智能整理、MCP 外部工具、联网视频下载和语音识别不可用；播放、阅读、编辑、摘录、空间和搜索等本地功能可以正常使用。随时可以在设置里更改模式。

### 支持 Mac、Linux 或手机吗？

不支持。kok 目前只提供 Windows 10 / 11 x64 版本，没有手机版，也没有 macOS 或 Linux 发布包。

### 能同步或使用云备份吗？

可以退出 kok 后手动备份 `data/`，或把导出的 `.koklib` 保存到移动硬盘或自己的云盘。便携包的原件范围取决于导出选项。kok 当前提供的是快照备份和恢复。[数据、备份与更新](../settings/data-backup.md)

## 反馈与其他

### 怎么反馈问题或建议？

请带上版本号、Windows 版本、操作步骤、预期结果和实际结果提交 Issues；安全问题请走私密渠道。反馈前不要上传资料原文、私密笔记或 API 密钥。
