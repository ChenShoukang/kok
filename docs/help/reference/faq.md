# 常见问题

下面是使用 kok 时最常遇到的问题。答案以 v0.10.1 Preview 的实际行为为准；如果问题涉及某类文件或某项能力，建议同时看[能力边界与未实现](boundaries.md)。

## 使用与数据

### 使用 kok 需要联网吗？

不需要。播放、阅读、编辑、整理和记录都在本机完成；只有使用 AI 功能、联网搜索、视频下载或联网匹配音乐信息时才会联网。

### kok 会把我的文件上传吗？

不会自动上传。只有你执行 AI 功能时，选定的内容才会发送给你在设置中配置的服务；纯净模式和私密文件夹会阻止 AI 请求。

### 我的数据保存在哪里？

资料索引、笔记、进度和设置保存在程序目录下的 `data/` 文件夹。实际路径可以在 **设置 → 资料库 → 关于 kok** 查看；原文件仍留在它们原来的位置。

### 换电脑时怎么迁移？

一起复制整个程序目录（包含 `data/`）最完整，再把原文件按原路径放回或重新导入。只想搬资料时，可以在 **资料库工具 → 资料检索与备份** 里导出便携资料库，但它不包含 AI 密钥、任务记录和私密库；私密文件夹的 `.kokvault` 备份需要原密码，也不包含原文件。

### 升级 kok 会丢数据吗？

不会，前提是保留 `data/`。更新只需替换程序文件，本版不改变数据格式；升级前备份 `data/` 更稳妥。

## AI 与费用

### Agent 为什么不可用？

Agent 需要智能模式并配置 AI 服务；纯净模式和私密文件夹不发送 AI 请求，对应模块停用时入口也会消失。没有配置模型时，仍可以先试统计、列表这类由本地规则直接回答的任务。

### AI 费用怎么算？

费用由 AI 服务商按实际用量计算。kok 里填写的单价、请求上限和额度用于估算与控制，不是服务商账单，也不能保证不超支。

### 忘记私密文件夹密码了怎么办？

密码无法找回：kok 不保存明文密码，也没有后门。原文件不受影响，但私密库里的索引和笔记无法再打开；请保留 `.kokvault` 备份并牢记密码。

## 能力与限制

### 为什么有些视频不能播放？

后缀能收录不等于能解码。kok 使用 WebView2 和系统编码，AVI、WMV、TS 等格式建议使用系统播放器；MKV 也可能因为编码或轨道不支持而无法完整播放。遇到无法播放的文件，可以在文件菜单里选择**使用系统应用打开**。

### 为什么 PPTX 打开后排版不一样？

kok 只重建基础文字和页面元素，复杂母版、图表、动画和嵌入对象不能完整还原；导出的 PPTX 也遵循同样的范围。

### “我的作品”里为什么没有显示某个文件？

“我的作品”按在 kok 中新建或修改过的内容和编辑草稿推导；只导入、还没有编辑过的资料只出现在资料库。作品级版本库尚未提供。

### 小说、音乐和视频能从零生成吗？

还不能。小说可以用文本编辑器写作，但作品级章节与设定管理尚未提供；可播放的音乐和视频需要生成引擎，本版只支持剪辑、拼接已有媒体。这些能力会分阶段接入。

### 纯净模式下哪些功能不能用？

Agent、翻译、智能整理、MCP 外部工具、联网视频下载和语音识别不可用；播放、阅读、编辑、摘录、空间和搜索等本地功能可以正常使用。随时可以在设置里更改模式。

### 支持 Mac、Linux 或手机吗？

不支持。kok 目前只提供 Windows 10 / 11 x64 版本，没有手机版，也没有 macOS 或 Linux 发布包。

### 能同步或使用云备份吗？

没有内置云同步或在线账户。你可以把 `data/` 或导出的便携资料库放进自己的云盘、移动硬盘手动保管；这类备份不包含原文件。

## 反馈与其他

### 怎么反馈问题或建议？

请带上版本号、Windows 版本、操作步骤、预期结果和实际结果提交 Issues；安全问题请走私密渠道。反馈前不要上传资料原文、私密笔记或 API 密钥。
