# 术语表

这页解释 kok 里反复出现的词。第一次遇到某个入口、卡片或提示时，可以回到这里对照。

## 资料与内容

- **资料库**：kok 中收录本地文件，并按视频、照片、音乐、文档、读书浏览的区域。
- **资料**：被收录进资料库的一份本地文件。kok 记录路径、索引、笔记和进度，不搬动原文件。
- **我的作品**：新建和继续编辑内容的区域，汇总文档、演示文稿、项目空间、摘录与配方。
- **作品**：在 kok 中新建或修改过、可以继续编辑的内容；作品导出后回到资料库欣赏，不在两处各存一份。
- **草稿**：编辑过程中自动保存、可以稍后继续的内容；kok 中新建或修改过的内容会出现在“继续创作”里，方便再次打开。
- **托管文档**：在 kok 中新建、保存在资料库内并可以直接保存编辑的文档；从外部导入的文档则通过草稿和另存副本的方式编辑。
- **查看器**：打开视频、音乐、照片、文档或电子书时的预览窗口，包含工作 / 沉浸布局、笔记与 AI 面板。

## 组织与创作

- **分类**：资料库里的文件夹式归类，可以拖放资料归类；分类不改变磁盘上的文件位置。
- **空间**：把同一主题的资料和摘录放在一起的组织方式，可切换网格、画布、时间线和图谱视图。
- **摘录**：保存的一段文字、一个音视频时间段或一块照片区域，并记录来源；点击可回到原处，不复制原文件。
- **智能集合**：保存下来的一组筛选条件，例如“最近七天导入、尚未阅读的 PDF”，结果随资料自动更新。
- **配方**：把读取、摘要、笔记、制作演示等步骤串联起来的可重复流程；运行前会预览整套步骤。
- **回顾**：按天查看打开记录与阅读、播放进度，并可以把回顾另存为笔记。
- **知识图谱**：用节点和连线展示资料与笔记之间已经建立的关系，不会自动推断新的事实关联。

## Agent 与扩展

- **Agent**：智能模式下接收自然语言任务、读取选定资料并提出可审核修改的协作入口。
- **任务**：在 Agent 中发起的一次工作请求，包含资料范围、要求、读取过程、修改建议和结果。
- **会话**：同一任务延续下来的对话上下文；重新打开任务记录可以继续，但未确认的写入不会自动重放。
- **成果**：任务结束时生成的结果，例如新文档、笔记或演示草稿；成果卡片可以打开文档、查看来源或继续修改。
- **技能**：给 Agent 的指令模板，内置整理、对比、读书笔记和制作演示四类，也可以导入自己的 SKILL.md。
- **MCP**：让 Agent 调用外部工具的协议，支持本地 stdio 和远程 HTTP，需要信任确认和逐次批准。

## 界面与模式

- **模块**：可以启用或停用的功能包。停用后入口消失，数据仍然保留；必需模块不能停用。
- **纯净模式**：只使用本地功能的模式，阻止 AI 请求，界面不显示 AI 入口。
- **智能模式**：开放 AI、翻译、Agent 和 MCP 的模式。进入模式本身不请求模型，执行 AI 功能时才发送所选内容。
- **私密文件夹**：资料库内的密码保护区域，加密索引、笔记和封面并禁用 AI；它不是第三种模式，原文件不加密。

> [!info]+ 资料和作品是两种身份
> 一份文件只有一个原件。被导入时它是“资料”；在 kok 中被新建或修改后，它会以“作品”的身份出现在“我的作品”里。两边看到的是同一份内容，不是两副本。
