# 键盘快捷键

kok 的大部分操作可以用键盘完成。快捷键会随打开的内容、使用模式和模块开关变化，下表的快捷键在对应条件成立时生效。

## 全局

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+K` | 打开“命令与资料”，搜索命令或文件 |
| `Ctrl+F` | 聚焦资料库搜索框（查看器未打开时） |
| `Ctrl+N` | 新建文档（需启用文档或演示模块，不适用于私密文件夹） |
| `Ctrl+S` | 保存当前编辑的文档或演示文稿 |
| `F8` | 在查看器或编辑器里切换工作 / 沉浸布局 |
| `Ctrl+Shift+I` | 打开所选资料的资料详情（检查器） |
| `Ctrl+Shift+A` | 打开资料旁的 AI 面板（上下文 AI，智能模式且功能可用时） |
| `Ctrl+Shift+L` | 锁定私密文件夹（在私密文件夹内） |
| `Esc` | 关闭预览窗口；全屏时先退出全屏 |

## 播放与阅读

| 内容 | 快捷键 |
| --- | --- |
| 视频 | `空格` 播放 / 暂停；`←` / `→` 前后跳跃；`↑` / `↓` 调节音量；`F` 或 `F11` 全屏；双击画面切换全屏（默认设置） |
| 音乐 | `空格` 播放 / 暂停；播放条上可切换上一首、下一首 |
| 阅读 | 滚动布局用 `←` / `→` 切换章节；分页布局用 `←` / `→`、`PageUp` / `PageDown` 或 `空格` 翻页；`Esc` 关闭阅读窗口 |
| 照片 | `←` / `→` 切换上一张、下一张 |
| 文件列表 | 方向键移动，`空格` 选择，`Shift` + 方向键扩展选择，`Ctrl+A` 全选，`Enter` 打开，`Shift+F10` 打开文件菜单，`Esc` 清除选择 |

## 编辑演示文稿

双击幻灯片文字后，按 `Ctrl+Enter` 完成这次输入。退出文字输入后，`Ctrl+Z` 撤销最近一次编辑，`Ctrl+Shift+Z` 重做。[制作与编辑演示文稿](../works/presentations.md)

## 改键与恢复

> [!tip]- 视频快捷键可以自定义
> 在 **设置 → 功能 → 视频操作 → 播放偏好**，或视频工具栏里的 **快捷键与跳跃设置**，可以更换播放键、跳跃距离和跳跃秒数，决定是否用方向键调音量，也可以整体关闭视频快捷键。输入文字或拖动滑块时，快捷键不会抢占操作。

> [!info]+ 快捷键没有反应时
> 先确认当前是否有输入框获得焦点，再看使用模式与模块开关：纯净模式没有 AI 面板，停用文档与演示模块后 `Ctrl+N` 也不可用。`Esc` 会先关闭最上层的菜单或预览窗口。
