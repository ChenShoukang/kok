# 版本与更新

这一页说明当前 kok 的版本状态、如何查看版本，以及怎样把已有数据带到新版本。

## 当前版本：v0.10.1 Preview

v0.10.1 把一级入口按使用场景重组成 **Agent**、**我的作品** 和 **资料库**：文件类型和工具移入各自区域，侧栏只保留三个目的地、私密文件夹和设置。

- 新增“我的作品”：新建 Markdown / DOCX / TXT / PPTX，继续编辑在 kok 中新建或修改过的内容，进入项目空间、摘录与配方，从已有视频、音频、PDF 和文档开始剪辑或整理。
- “资料库”首页集中继续观看与阅读、收藏、最近打开、分类和资料库工具；观看、收听、阅读、字幕、书签和播放队列保持独立可用。
- Agent 在后台播放音乐时仍然可用，输入区和播放条不会互相遮挡。
- 本版不改变数据格式；小说章节 / 设定管理与音视频从零生成仍分阶段接入，见[能力边界](boundaries.md)。

## 查看版本

打开 **设置 → 资料库 → 关于 kok**，可以看到 kok 版本、WebView2 版本和资料库位置。反馈问题时请附上这些信息。

## 更新方式

kok 没有自动更新。更新时先备份 `data/`，下载新版本 ZIP 后解压到新的程序目录或覆盖旧程序文件，再保留原来的 `data/` 启动新版本。删掉 `data/` 会丢失应用内记录，但原文件不受影响。安装细节见[安装 kok](../getting-started/install.md)。

> [!warning]+ 更新前先备份
> `data/` 里是资料索引、笔记、进度和设置，不是可以随手重建的缓存。预览版仍在持续调整，更新前请保留 `data/` 的独立备份。

> [!info]+ Preview 预览版
> 当前版本是未签名的 Preview 预览版，功能和界面仍可能调整。发布包提供 SHA-256 校验文件，请从 Release 页面下载；重要资料请另外保留副本。
