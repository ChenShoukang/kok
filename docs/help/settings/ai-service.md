# 配置 AI 服务

智能模式下的翻译、内容助手、智能整理和 Agent 共用一套 AI 服务配置。这页说明怎样填写接口、读取模型列表、测试连接，以及密钥和联网的边界。

## 打开并填写服务

选择 **设置 → 功能 → AI 服务 → 配置 API**。表单包括：

- **服务商**：11 个常见服务的预设，或 **自定义兼容服务**。预设只提供起始地址，不代表所有模型都支持全部功能。
- **API 地址** 与 **模型名称**：可按服务商说明填写。本机 Ollama / LM Studio 使用 HTTP 地址，不需要填写密钥，但要先启动服务并加载模型。
- **API 密钥**：保存后不会回填显示；本机免密预设会在保存时清除已有密钥。

选择 **读取模型列表** 会向当前地址的 `/models` 发起请求，帮助选择模型，不会发送资料内容；服务不提供列表时可以手动填写。选择 **测试连接** 会先保存表单再发送一次短翻译请求，可能产生服务费用。

## 翻译偏好与高级设置

- **翻译偏好**：设置目标语言，并决定是否自动翻译打开的字幕、章节或 PDF 当前页（默认关闭）。
- **高级兼容设置**：输出长度参数可选自动、`max_tokens` 或 `max_completion_tokens`。
- **联网与视觉**：勾选 **模型支持图片输入（视觉）** 后，Agent 才能读图回答；**联网搜索服务地址** 可填写兼容 SearXNG 的服务，网络读取仍会在任务中逐次审批。

> [!warning]+ 注意
> **测试连接** 会真实请求服务并可能计费。语音识别不在 AI 服务里配置：视频的 **生成字幕** 会单独选择本地 Whisper 或语音 API，聊天服务的密钥不会转发给语音服务。

## 密钥、联网与费用

密钥使用 Windows 数据保护（DPAPI）加密，仅由本机程序解密；更改 API 地址后需要重新填写密钥。纯净模式和私密文件夹会阻止 AI 请求。进入智能模式本身不联网，只有执行翻译、问答、整理等 AI 功能时，选定内容才会发送到配置的服务。长资料可能只发送节选，实际费用以服务商账单为准。
