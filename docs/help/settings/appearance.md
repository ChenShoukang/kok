# 外观与字体

这页说明 **设置 → 外观** 中的选项：主题、自定义配色、字体与界面语言，以及预览窗口的默认布局。

## 界面外观与自定义配色

在 **设置 → 外观** 中，**界面外观** 可以选择 **浅色**、**深色** 或 **跟随系统**，选择后立即生效并记住。

选择 **自定义配色** 一行右侧的 **调整配色** 可以打开配色面板：

- 启用后可以选预设，或分别调整 **背景颜色** 与 **玻璃颜色**。
- **玻璃不透明度** 范围 15%–95%，**模糊程度** 范围 0–48 px。
- 浅色和深色配色分别保存，切换主题后编辑的是对应的一套。
- 选择 **恢复默认配色** 可以回到初始颜色。

## 字体与导入

**常用字体** 同时应用于界面和正文阅读，提供内置的 **得意黑**、**霞鹜文楷轻便版**，以及系统字体、微软雅黑、宋体、楷体等选项；没有手动切换时使用系统字体。内置字体离线可用，不必安装到 Windows。

选择 **导入字体** 可以添加自己的本地 TTF 或 OTF 文件，单个文件不超过 20 MB；导入后会出现在字体列表中并立即应用。阅读时如果还需要单独的正文字体，可以在阅读器的 **阅读排版** 中设置。

> [!tip]- 小提示
> 内置字体按需加载，不安装到系统；轻便版未覆盖的生僻字会由系统字体回退。阅读器的字体、字号与纸色设置优先于这里的界面字体。

## 界面语言

**界面语言** 提供中文和 English，切换后界面立即更新，无需重启。名称、笔记与文档内容不会被翻译；首次启动的模式选择页也有中 / EN 切换。

## 动态效果与预览窗口密度

kok 尊重 Windows 的动画效果设置，系统关闭动画时界面也会减少动态效果，不另外提供开关。

查看器默认密度按资料类型决定：视频、照片和读书默认 **沉浸** 布局，文档默认 **工作** 布局。打开资料后可以按 `F8` 或选择标题栏按钮在两种布局间切换，选择会按类型记住。
