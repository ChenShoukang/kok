# 数据、备份与更新

kok 的资料库记录保存在本机。这页说明数据位置、导出与恢复的方式，以及移除资料、升级程序时哪些内容会保留。

## 数据位置

资料索引、笔记、进度、封面、设置和私密库都保存在程序目录下的 `data/` 文件夹。选择 **设置 → 资料库 → 关于 kok** 可以看到实际的 **资料库位置**。原文件不会因为导入而被复制或移动，它们仍在原来的路径。

需要独立资料库时，可以带 `--data-dir` 参数启动 kok，指定另一个目录。

## 导出、恢复与换电脑

- **设置 → 资料库 → 资料库备份 → 导出**：生成 JSON 快照，包含索引、笔记、进度、空间与摘录等应用内记录，**不包含原文件**。
- **资料库工具 → 资料检索与备份 → 导出便携资料库**：生成 `.koklib`，包含托管文档和资料记录，其他原件可选包含。**恢复到新资料库** 会校验包并创建独立新库，默认使用纯净模式。缺失原件可以重新关联。

JSON 快照用于保存和核对应用内记录，没有内置的一键导入；换电脑或恢复资料库请使用便携包流程，详见[资料库工具、历史与备份](../library/library-tools-backup.md)。

## 移除资料与私密备份

在卡片的更多操作中选择 **更多文件操作… → 从资料库移除**，只会删除 kok 中的记录与索引，原文件保留。私密文件夹中的 **导出** 会生成 `.kokvault` 加密备份，不含原文件与 AI 密钥，仍需原密码读取；备份范围与恢复方式见[私密文件夹](private-folder.md)。

> [!NOTE]
> JSON 快照和 `.kokvault` 保存的是应用内记录，原文件要另行备份。`.koklib` 不包含 Agent 对话、任务记录、私密库和 AI 密钥。换电脑后打开恢复的库，抽查几份资料和作品，再重新配置需要的 AI 服务。JSON 快照为明文，请妥善保存。

## 更新与版本

升级前退出 kok，复制当前资料库作为备份。原地升级保留 `data/`。新目录解压时，把原 `data/` 复制到新程序目录，或通过原来的 `--data-dir` 启动。版本和下载链接见[版本与更新](../reference/versions.md)。
