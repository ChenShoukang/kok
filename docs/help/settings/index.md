# 设置概览

设置集中管理 kok 的外观、功能开关和资料库数据。侧栏底部的齿轮按钮就是入口；第一次调整主题、配置 AI 或关闭某个模块时，从这里开始。

## 打开设置

选择侧栏底部的 **设置** 打开设置窗口。窗口顶部有三个标签页：**外观**、**功能**、**资料库**，选择标签或用键盘左右方向键切换；右上角关闭按钮或 `Esc` 关闭窗口。改动会保存在本机。

## 三个标签页分别放什么

| 标签页 | 主要设置 |
| --- | --- |
| 外观 | 界面语言、界面外观（浅色 / 深色 / 跟随系统）、自定义配色、常用字体、导入字体 |
| 功能 | 当前模式与 **更改模式**、启动页、AI 服务、指令技能、外部工具 MCP、视频操作、智能整理 |
| 资料库 | 资料库备份导出、体验示例、模块管理、关于 kok |

**关于 kok** 显示版本、WebView2 版本、资料库位置和常用快捷键，旁边还有 **使用帮助**。

## 常用设置

- 换主题、配色或字体：[外观与字体](appearance.md)
- 调整阅读排版与视频、音乐播放：[阅读与播放偏好](reading-playback.md)
- 连接 AI 服务：[配置 AI 服务](ai-service.md)
- 启用或停用功能：[模块管理](modules.md)
- 加密部分内容：[私密文件夹](private-folder.md)
- 备份、恢复与升级：[数据、备份与更新](data-backup.md)

## 与模式、私密文件夹的关系

设置中的功能行会随状态变化：纯净模式隐藏 AI 服务、启动页、指令技能、外部工具 MCP 和智能整理，智能模式才显示它们。**更改模式** 也在 **功能** 标签页。私密文件夹不是第三种模式，解锁后设置窗口顶部会显示 **私密文件夹** 行，可以 **锁定文件夹**，AI 相关设置不可用。

> [!info]+ 说明
> 设置和资料库记录一起保存在本机。导出的便携资料库不含 AI 密钥，密钥单独加密保存在本机。
