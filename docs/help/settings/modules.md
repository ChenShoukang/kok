# 模块管理

模块是可以单独启用或停用的功能包。关闭用不到的功能可以让侧栏和命令更干净，数据不会因此丢失。

## 打开模块管理

选择 **设置 → 资料库 → 模块 → 管理**，打开 **模块管理** 窗口。每个模块显示名称、启用开关和一句状态：

- **必需**：固定启用，开关不可关闭。
- **已启用 / 已停用**：可以切换。
- 小字部分说明它包含的资料类型、是否需要联网或使用 AI。
- 展开 **能力与数据** 可以看到模块的字段和提供给 Agent 的工具。

## 启用与停用

切换开关后，kok 会先保存当前编辑；如果该模块还有独立的预览窗口，需要先关闭对应窗口。停用后：

- 对应的侧栏入口、命令和 Agent 工具会隐藏，直接调用也会被拒绝。
- 已有资料、笔记和记录保留，重新启用即可恢复使用。

**新建文档与演示格式** 跟随模块：关闭 **文档与读书** 或 **演示文稿** 后，新建对话框里对应格式会消失；全部关闭时新建入口隐藏，`Ctrl+N` 也不再处理。

## 必需模块与私密文件夹

**核心**、**活动** 和 **窗口与资料库** 是必需模块，不能停用。在私密文件夹中解锁后，所有模块开关都不可调整，私密内容始终使用受限的功能集。

> [!info]+ 说明
> 模块开关只影响入口和可用能力，不会删除已收录的资料；之后重新启用同一模块，原来的内容和记录仍在。
