# 私密文件夹

私密文件夹是资料库里的密码保护区域，不是第三种使用模式。它把应用内的记录加密，同时禁用 AI；原文件仍留在原位置。

## 创建与解锁

选择侧栏的 **私密文件夹**，或资料库首页的私密文件夹卡片。第一次使用时创建密码并再次确认，密码长度为 8–256 个字符；之后每次打开都需要输入密码。离开窗口、最小化或闲置 5 分钟后会自动锁定，也可以选择 **锁定文件夹**、按 `Ctrl+Shift+L` 或返回资料库立即锁定。重启 kok 后需要重新输入密码。

> [!warning]+ 注意
> 密码无法找回。请用密码管理器或安全的位置保存它；忘记密码后就无法再解锁这些内容。

## 加密范围与 AI 边界

私密文件夹加密索引、笔记、封面和关联数据，内容不会出现在普通资料库的分类、搜索、摘录、空间或知识图谱中。文件夹内不使用 AI，纯净模式与智能模式都一样。

**原始视频、照片、文档仍在原路径，不会被加密、移动或隐藏。** 普通资料库中已收录的同一原文件也不会因此自动隐藏；如果不想让它出现在普通库，需要先把它移入私密文件夹。

## 移入与清理

在普通资料库中选中资料，把它们拖到侧栏或首页的 **私密文件夹** 入口，会先弹出确认窗口（还没有私密文件夹时会先要求设置密码）。kok 会先保存加密记录、封面与关联摘录，再清理它在普通库中的记录、正文索引、回顾条目、空间成员关系和相关撤销字段。混合操作中其他资料的修改会保留；目标已存在同一文件时会停止移动；清理失败会报错并保留待办记录，下次启动时重试。

## 备份与恢复

在私密文件夹中选择 **设置 → 资料库 → 资料库备份 → 导出**，会生成 `.kokvault` 备份，包含加密的索引与笔记，不含原文件、AI 密钥或缓存。备份仍需原密码才能读取；当前没有一键恢复按钮，手动恢复步骤与保护边界见[使用模式与私密文件夹](../../MODES.md)。
