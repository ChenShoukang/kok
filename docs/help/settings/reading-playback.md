# 阅读与播放偏好

kok 的阅读排版、视频播放和音乐播放各有自己的控制项。这页告诉你它们分别在哪里，以及哪些设置会保存在本机。

## 阅读排版

打开书籍、文档或 PDF 后，在阅读器工具栏选择 **阅读排版**（PDF 还可使用 **夜间文档**）：

- **正文字体**、**字号**（14–48 px）和 **阅读配色**：跟随界面、柔和纸色、护眼绿或夜间阅读。
- **行距** 1.3–2.6；阅读书籍和文档时还可以展开 **更多排版**，调整 **字距**、**段落留白** 和 **正文宽度**。
- 布局可选 **连续滚动**、**单页** 或 **双页**；窗口较窄时双页会自动显示单页。
- 读书与文档的阅读设置分别保存，也可以选择 **恢复默认排版**。

PDF 使用 **夜间文档** 切换深色显示，阅读排版中可以调整字体与字号，但不提供分页布局和更多排版选项。

## 视频播放设置

视频底部控制条提供音量、**播放设置**、画中画和全屏。打开 **播放设置** 可以：

- 选择 0.5×–3× 的倍速，或打开 **静音自动加速**，检测到无声片段时临时加速。
- 切换字幕轨，或选择 **载入字幕** 手动添加外挂字幕。
- 展开 **快捷键与跳跃设置** 调整快捷键与跳跃距离。

完整设置也可以在 **设置 → 功能 → 视频操作 → 播放偏好** 中修改：启用视频快捷键，选择播放 / 暂停键（空格、`K` 或 `P`）、跳跃键（方向键或 `J` / `L`）、每次跳跃的秒数，决定是否用方向键调音量、是否双击全屏。视频音量会保存在本机。

## 音乐播放

音乐播放器提供 **随机播放**、上一首、播放 / 暂停、下一首、**循环播放**、播放队列和音量滑杆；音量会被记住。关闭预览窗口后音乐继续播放，可以从底部播放条重新打开。专辑、歌手和队列的组织方式见[收听音乐与音频](../library/listen-music.md)。

## 查看器工作与沉浸布局

查看器顶部有 **查看**、**编辑**、**笔记**、**AI** 标签（随资料类型和模块变化）。**工作** 布局显示这些标签与侧边面板，方便边看边记；**沉浸** 布局收起面板，把空间留给内容。按 `F8` 或选择标题栏的布局按钮切换，kok 会按资料类型记住每种内容的选择。

> [!tip]- 小提示
> 输入文字或拖动滑杆时，视频快捷键不会抢占操作；如果不想用快捷键，可以在 **播放偏好** 里整体关闭。阅读设置的调整会立即应用，原文件不会被修改。
