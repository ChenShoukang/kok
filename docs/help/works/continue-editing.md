# 继续创作项目与草稿

[帮助中心](../index.md) / [我的作品](index.md)

要接着写一份稿件，从 **继续创作** 打开。要找回与同一目标相关的资料、要求和成果，从 **创作项目** 打开。

## 在同一个项目里接着做

1. 打开 **我的作品 → 创作项目**，在对应卡片点 **打开项目**，查看目标、要求、资料和成果。
2. 点成果名可以打开文件。点 **继续创作** 会进入 Agent，用新会话接着处理这个项目。
3. 确认输入框上方显示项目名称。默认范围包含项目资料和近期成果，去重后最多 24 份。如果只想用其中几份，可以点 **添加资料** 明确选择。

已保存并登记到项目的成果可以跨会话、分支和重启找回。要找旧对话，在 Agent 的 **会话** 中切换。要离开当前项目，点项目横幅上的关闭按钮。[创作项目的完整示例](../getting-started/first-agent-project.md)

## 项目搜索与交付记录

1. 从 **我的作品 → 全部项目** 按名称或目标搜索。这里也能找回最近 24 个卡片以外的项目。
2. 打开项目。Agent 登记的成果可以直接打开。手动创建的文档或 PPT，可点 **添加成果** 加入项目。
3. 在成果的编辑器里用 **另存副本** 或 **导出 PPTX** 交付。成功保存后回到项目的 **交付记录**，即可核对文件名、导出时间、位置和导出指纹。点 **在文件夹中显示** 直接定位副本。

记录的是导出当时的文件。取消导出不会产生记录。文件移走后会显示可能已移动。从资料库移除副本时，对应记录不再显示。交付记录保存在当前本地资料库，不随便携包迁移。

## 列表从哪里来

**我的作品** 的 **继续创作** 会收集两类内容：在 kok 中新建的托管文档，以及对已有文件保存过编辑草稿的项目。列表按最近修改时间排序，最多显示 24 个；没有内容时显示“从第一件作品开始”。

卡片右下角的状态有含义：

- **草稿**：还有正在进行的编辑草稿，例如正文、PDF 页面整理、视频或音频剪辑。
- **已创建**：新建后还没有产生编辑草稿。

## 打开后进入哪里

选择卡片会打开对应的编辑器，而不是先回到资料库：

- MD、DOCX、TXT：正文编辑器，可以继续编辑或另存副本。
- PDF：页面整理工作区，可以重排、旋转和标注页面。
- 视频、音频：剪辑工作区，可以继续调整片段。
- PPTX：演示文稿查看器，并自动进入编辑状态。

## 关闭、保存与找回

kok 管理的文字文档和可直接保存的 PPTX 会写入作品文件。编辑导入的原件时，保存的是应用内草稿。下次从 **继续创作** 打开可以接着改；要交付给别人，用 **另存副本** 或 **导出 PPTX** 生成新文件。

托管文字文档可用 **版本** 浏览和恢复保留的历史稿，并为历史版本命名。PPTX 暂无同样的版本对比面板，阶段稿可导出为单独的副本。[对比和恢复旧稿](create-documents.md#对比和恢复旧稿)

## 成品在哪里

导出的文档、演示、图片和媒体副本都会进入 **资料库**，按类型出现在对应筛选中，可以像其他资料一样播放、阅读、收藏和分类。作品本身不另存一份文件，之后仍通过内容卡片和编辑草稿继续访问。
