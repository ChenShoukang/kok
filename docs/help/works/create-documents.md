# 新建与编辑文档

[帮助中心](../index.md) / [我的作品](index.md)

这页说明怎样在 kok 中新建一份文字文档、选择模板，并在编辑器里继续写作与导出。写 Markdown 笔记、Word 文档或纯文本都从这里开始。

## 新建文档

在 **我的作品** 选择 **新建作品**，或按 `Ctrl+N`、选择顶栏的 **新建**，都会打开同一个 **新建文档** 对话框：

- **文档格式**：Markdown、Word（DOCX）或纯文本（TXT）；启用了演示文稿模块时还会看到 PowerPoint。
- **文档名称**：默认是“未命名文档”，创建后仍可以另存副本。
- **分类**：可以选择已有分类，或保持未分类。
- **模板**：空白文档、日常记录、会议纪要、阅读笔记；模板只用于文字文档，选择 PowerPoint 时不可用。

选择 **创建并编辑** 后进入正文编辑器；选择 PowerPoint 则进入演示文稿工作区。新建格式入口会跟随对应模块的启停，模块停用时格式按钮消失。

## 编辑与预览

编辑器左侧是 **编辑正文**，右侧是 **阅读预览**：

- 预览支持 1 栏或 2 栏，并可调整预览字号。
- 格式工具栏提供加粗、斜体、标题、列表、引用、撤销与重做。
- 选择 **Markdown** 按钮可以在富文本编辑与源码之间切换，Markdown 文件默认显示源码。
- 标题栏会显示文件名与格式，例如 `Word · DOCX`。

kok 新建并管理的文档会自动保存，状态栏显示 **已保存** 或 **有未保存的修改**。有未保存改动时，按 `Ctrl+S` 或点 **保存** 可先查看保存前的差异，再确认写入。保存失败会保留恢复草稿。导入的原件用 **保存草稿** 继续编辑，或 **另存副本** 导出。

## 对比和恢复旧稿

1. 在托管的 Markdown、TXT 或 DOCX 文档中点 **版本**。
2. 选择一个历史版本，查看可用的内容差异。Markdown 和 TXT 可逐行对比，DOCX 可以比较能提取到的正文。正文不可用时，可通过文件大小和校验值识别版本。
3. 可以给历史版本添加 **命名检查点**，例如「送审前」。需要恢复时点 **恢复此版本** 并确认。恢复会写入同一文档，也可从操作历史撤销。

版本和检查点适用于 kok 管理的文字文档。演示文稿可撤销当前编辑操作，重要节点可以导出副本保留。[版本与局部改稿](../../VERSIONS_0.10.11.md)

## 导出与限制

选择 **另存副本** 会生成一个新文件并加入 **资料库**，原文件保持不变。文字文档可以导出为 Markdown、TXT、DOCX 或 EPUB。

> [!warning]+ 注意
> DOCX 和 EPUB 导出重建的是简洁排版正文，不保留原文件里的复杂版式、图片、表格布局、嵌入对象和交互表单。需要保留原始版式时，请同时保留原件，不要只依赖导出副本。

## 从 Agent 创建文档

在智能模式下，可以让 Agent 把资料整理成 Markdown 笔记。核对拟保存的正文并执行后，从 **成果** 或 **我的作品 → 继续创作** 打开。

要改一段，先保存文档，再选中文字并点 **让 Agent 改这段**。在输入框补充要求并发送，确认预览只改了选中的内容后再应用。[审查与撤销修改](../agent/review-changes.md)
