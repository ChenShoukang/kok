# 剪辑已有音视频与整理 PDF

这页说明怎样从 **我的作品** 的 **工具** 区，对已有的视频、音频、PDF 和文档进行二次加工。kok 只处理已有媒体，不负责从零生成音视频。

## 选择来源

在 **工具** 区选择 **剪辑已有视频**、**剪辑已有音频**、**整理 PDF 页面** 或 **编辑已有文档**，会打开一个选择窗口：输入名称可以筛选，列表中只显示符合该类型的资料。选择一条即可进入对应编辑器。

也可以先在 **资料库** 打开文件，再选择标题栏的 **编辑** 进入同一个编辑器。原文件不会被改写。

## 剪辑视频与音频

编辑器提供入点、出点、选段预览，以及时间线与片段管理：

- **剪切与分割**：设置开始与结束时间后选择 **加入片段**；把播放位置放在选段中间，选择 **分割** 可以拆成两段。
- **跨素材时间线**：从 **素材** 下拉切换到同类型的其他文件，片段会按顺序拼接；拖动片段可以调整顺序，最多 50 个片段。
- **调整**：播放速度、音量、淡入淡出、旋转与静音；视频可以给当前片段填写字幕文字，字幕随片段导出为可见文字，不是多轨字幕。
- **导出**：视频导出 MP4，音频导出 WAV、MP3 或 M4A，结果作为新文件加入资料库。

音频在文件可解码且不太大时会显示实际波形。导出依赖可选的本地 FFmpeg / FFprobe：智能模式可以安装组件，纯净模式可以选择已有组件；未就绪时界面会提示。

## 整理 PDF 页面

**整理 PDF 页面** 会打开页面整理工作区：

- 拖动页面缩略图调整顺序，或用 **前移 / 后移**、**旋转**、**移除** 按钮编辑页面。
- 选择 **添加 PDF** 可以合并其他 PDF 的页面。
- 选择 **编辑页面** 进入画布：框选区域替换文字，使用文字、画笔、矩形、箭头和遮挡工具，配合图层与撤销 / 重做。
- 选择 **保存草稿** 保留项目，选择 **另存副本** 导出新的 PDF。

画布编辑过的页面会按图像导出，原页文字不再保留；未编辑的页面继续复制原有内容。页面整理项目最多 500 页，源 PDF 数据合计最多 32 MiB。

> [!warning]+ 注意
> 媒体导出需要 FFmpeg / FFprobe，未安装时不能生成新的音视频文件。kok 不会修改原文件，所有结果都是另存的新副本。

## 能力边界

本版只支持已有媒体的剪切、拼接与整理。从零生成可播放的音乐或视频需要相应的生成引擎，尚未提供。
