# 我的作品概览

我的作品用来新建内容、继续未完成的创作，并进入项目空间、摘录和配方等创作工具。想从空白开始写文档或做演示时，从这里进入。

## 这个区域解决什么

**我的作品** 是三个一级入口之一，和 **Agent**、**资料库** 并列。它把开始创作与继续创作放在同一个页面：新建作品、打开上次没写完的稿件、从已有视频音频 PDF 进入剪辑整理，都在这里完成。

页面从上到下分为三部分：

- 标题行：显示 **我的作品** 和 **新建作品** 按钮，副标题会提示还有几个可以继续的草稿。
- **继续创作**：列出在 kok 中新建或修改过的内容，按最近修改时间排序，最多显示 24 个。
- **工具**：**项目空间**、**素材摘录**、**创作配方**，以及 **剪辑已有视频**、**剪辑已有音频**、**整理 PDF 页面**、**编辑已有文档**。看不到的按钮说明对应模块已停用。

## 什么算作品

在 kok 中新建或修改过的内容会出现在 **继续创作** 里：新建的 Markdown、DOCX、TXT 和 PPTX 属于作品；对已有文件保存过编辑草稿（正文、PDF 页面、音视频剪辑）的项目也会作为草稿出现。

卡片右下角显示状态：**草稿** 表示还有编辑草稿未完成，**已创建** 表示新建后还没有产生编辑草稿。选择卡片会打开对应编辑器。

> [!info]+ 说明
> 作品和资料不是两份文件。新建的作品保存在 kok 的资料库索引里，导出的成品会作为新文件进入 **资料库**，可以用同一套播放器和阅读器欣赏；作品不会额外复制原始素材。

## 与资料库的分工

**资料库** 负责观看、收听、阅读和整理已有内容，**我的作品** 负责新建和继续编辑。资料可以加入项目空间、被摘录引用或交给 Agent 使用，但这些操作不会把文件搬到别处。

## 当前能力与分阶段

本版可以新建文档与演示文稿，也可以剪辑已有音视频、整理 PDF 页面。小说作品级的章节与人物设定管理、从零生成可播放的音乐或视频，以及作品级原生版本库尚未提供，会在后续版本分阶段接入；现在可以用操作历史和导出副本保管成果。
