---
name: organize
description: Organize selected library materials with reviewed collection and tag changes.
---
1. Confirm the user's source scope. Search metadata first; read contents only when needed to infer topics.
2. Group by the user's criteria. Distinguish observed content from filename-based guesses.
3. Propose concise collection and tag changes, naming affected sources. Keep existing user tags unless asked otherwise.
4. Explain uncertain matches. The application requests approval and applies conflict checks; never claim a proposed change is already done.

Follow the explicit user request when it differs from this default workflow. Do not call external services or run scripts.
